## 接入边界

当前两个 `heroSlots` 是图库ID为105301的占位图片，**不能**把100001、模板索引或本资产名称填进它们就视作接通。图元组需要专用宿主，接入者须保留独立文字/按钮与输入层。

源逻辑画布480×270为16:9，1280×720采用等比8/3缩放；其他画布按min(width/480,height/270)居中contain。不得拉伸进320×420竖版肖像槽，也不擅自裁切人物或改变UI布局。最终布局由现有UI接入工作协调。

完整导出仍为`IMAGE_PREFAB_ID=0`，必须绑定本次候选返回的真实图片控件模板索引。100001只是矩形图库资产ID。原导出会设置宿主大小并同步创建所有控件，不能直接挂到UI根节点。正式启用前必须完成有界加载、取消与回收适配，并逐步验证专用宿主创建、显示、切页、进入战斗后的释放。
