# 一次导入的2D／2.5D／3D压力测试

这是隔离测试工具，不装配正式游戏，也不代表手机或正式美术验收通过。[实测结论与缺口](../../../docs/art/art-pressure-results.md)。

## 构建与验证

在仓库根运行，Node>=22，先 `npm ci --ignore-scripts`。本机工具路径以 `docs/TOOLCHAIN.md` 为准，脚本不再绑定某台机器的D盘。

```powershell
$env:MILIASTRA_MCP_ROOT='D:/MiliastraTools/genshin-miliastra-mcp'
node art/spikes/art-pressure/run-verify.mjs
node art/spikes/art-pressure/prepare.mjs <干净美术测试底图.gil> <20档输出目录>
node art/spikes/art-pressure/extend-scenes.mjs <20档输出目录> <41档输出目录>
```

输出目录应新建且为空。底图必须是无其他玩家所属动态实体的美术测试副本；服务端会清理测试玩家所属实体，不能拿正式游戏存档当底图。始终 `MILIASTRA_ALLOW_LIVE_WRITE=0`，原文件不覆盖，副本不发布。

先构建41档总副本，再只导入 `art-pressure-all-scenes.gil` 一次。每档从运行时切换，不逐档重新导入。`candidate.json` 保存副本hash、模板/模型和静态检查结果；准备成功不等于导入或游戏里通过。更新后须重新构建、导入和核对本轮外部Lua，旧截图不算新版本实测。

## 档位

| 档位 | 内容 |
|---|---|
| 1–20 | 空载、10技能图标、1/3/5角色、1/5/10卡牌、轻重混合；257/939图元角色、15/343图元卡牌 |
| 21–32 | 7/28/84原生模型、192/768/1536图元合成视差、组合负载；仅压力替身 |
| 33–38 | 同构图成品样板：32模型原生3D、207图元2.5D，各自空载/轻组合1435/重组合8125 |
| 39–41 | 同207图元成品构图的纯2D静态背景，空载/轻组合/重组合 |

扩展副本首次从33自动巡测到41，每档15秒；服务端清理和创建时间另计。2秒预热+8秒回调采样；自动巡测完成停在最后一档。按钮可上一档/下一档、清空、重建、切换整组移动、缓存复用，Auto从1开始巡测全部41档。33/34/39隐藏调试文字便于截纯场景；自动切到后续档会恢复；失败始终显示诊断。

纯2D与2.5D保留同样207图元/13容器，前者不移动，后者只移动五层。前景角色在Motion开启时仍移动。它不是自定义PNG导入测试。3D数量、2D图元数和draw call不是同一单位。

## 证据规则

- 试玩必须显式 `clientScriptLog:true`，本轮订阅日志并取得 `ARTPRESS_READY`。
- 每次原生场景变更有递增requestId；仅本次同ID、同分组、精确实体数ACK后开始预热。错数量、15秒无确认、创建异常均停止采样并显示诊断。Clear也等零实体确认，不用旧ACK证明清理成功。
- 清理每次重新查询列表首元素，分批16件，避免遍历期间删除漏掉一半实体。退出OnDestroy交给引擎，不在其销毁回调重复Destroy。
- `ARTPRESS_DT` 是脚本OnUpdate回调间隔，**不能当FPS、GPU帧时或手机性能**。实际帧率另用ETW/设备工具，并保持相同画质、分辨率和空载对照。
- 257图元角色的形象质量不足以批准正式美术；压力跑完也不等于画面、拖放、输入和整场游戏通过。
- 使用键鼠、切前台、导入和试玩之前，须先与用户约定本轮开始时间和持续时长，旧授权不续期。

离线入口用Fengari `-e dofile(...)` 保留失败退出码。验证包含真实四套资产导出源、41档数量、两种背景模式、清理/重建、旧ACK/错误数量/超时/创建失败。它只验证契约；生产样板的美术和手机表现需要实机。
