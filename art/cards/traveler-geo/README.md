## 文件契约

- `catalog.json`：只按两个显式 `card_id` 登记相对 `asset.json` 路径；`runtime.status=unbound`。它不是新 renderer，不向 `ui_theme` 填写虚构原生图片ID。
- `source.png`：内置 imagegen 实际生成的1881×836源图，非用户上传；仅作设计/重绘源，不能作为外部PNG直接导入游戏。
- `prompt.txt`：该源图实际最终提示词，原字节保留。提示词中的请求尺寸不是输出尺寸；以PNG和元数据的1881×836为准。
- `native-art.json` / `native-art.lua`：固定编辑器导出的144×64可编辑场景与真实运行绘图表。JSON原字节保留；Lua仅去掉导出器多余的1个末尾LF，保留一个最终LF，绘图表和代码不变。没有完整卡面或静态名称/费用/效果文字。
- `preview-native.png`：已生成的真实Lua去快照回读4×预览（576×256），不是源图缩略图，也不是官方客户端截图；本切片不重新生成或改绘。
- `asset.json`：源/提示词/导出/预览SHA256、尺寸、控制计数、版本、来源、认可范围和未验状态。文本摘要按LF规范化，PNG按原始二进制计算；Lua另登记 `originalExport` 的原始SHA/字节数和精确移除的末尾LF数量，可由入库文件加回该LF还原原导出。元数据和catalog自身摘要登记在 `docs/legal/assets.json`。

两张源图恰为2.25:1，完整等比适配144×64，偏移为0、无裁切/拉伸。旧 `../geo-samples/` 是144×34未量产候选及143控件池，保持原样；本目录不覆盖、拉伸或冒用旧池数据。

## 已认可与仍待验

认可范围是这两张的源设计、实际原生重绘和离线完整卡面视觉。完整卡面和动态文字继续归已有共享装配入口管理；不把它们烘焙进插画资产。

- 两份Lua仍为 `IMAGE_PREFAB_ID=0`，没有真实游戏模板绑定。正式界面仍使用已有 `placeholder-type-icon` 类型图标回退；不能把图库ID当模板索引，也不能直接挂本导出到生产stage。
- 保留既有导出器清理代码，只表示源码存在；重复进入/退出、生命周期回收和错误清理的实机行为尚未验证。
- 独立艺术区与完整卡面1×离线比较一致；完整卡面4×严格像素一致仍为 **FAIL**：整备25像素、重剑47像素量化差异。未抬阈值，视觉认可不把此结果改写为PASS。
- 官方导入、混合XYZ/蒙版设备显示、加载时间、1/5/10卡同屏、真实中文、手机/主机性能与完整UI验收仍待验。高控件样本不因此获准启用或扩产；没有批准其余卡池。
