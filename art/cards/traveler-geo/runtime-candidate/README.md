# 现有72张源图的原生候选

当前比赛先使用已有图，不重绘设计。`rectangles.json`包含75张职业牌中除已精修armaments/cleave/heavy_blade之外的72张；三张原有精修数据保持原字节。状态/诅咒牌不属于该75张清单。

实际输入为仓库已提交的144×64预览（不是重新下载的高清LFS源图），逐图SHA和路径在记录中。固定`wwh177/miliastra-image-algorithm@fdc76f28393babb7b960e09014ee43db36575c03`在离线隔离目录运行；不分发该上游源码，也不复制其未明确授权的运行时。现有Lua卡面负责写原生图片属性。

每块自有数据格式为14个十六进制字符：x/y/w/h各一字节，RGB各一字节。坐标以144×64左上角为原点，矩形覆盖半开区间；不含名称、数值、规则或文字。每卡不超过2657块，全覆盖、无越界、无重叠；透明输入会拒绝，不丢弃alpha或暗加底色。转换使用8bit，逐卡选最小可满足控件预算的整档STD，分布及所有失败参数见`conversion-report.json`。

总180873块，单卡2072–2656。4张需STD10，其余3–8。与源图不是无损相等；2倍查看可见块化，原源图不覆盖。报告里的proof PNG是离线审查产物，未重复入库；可由记录的sourcePreview和矩形数据重建对照。记录的自动/人工离线检查不等于Owner逐张确认，也不等于原生编辑器导入、官方容量或手机验收。

正式构建生成独立`abyss_ready_card_assets`数据模块，只在真实模板索引绑定后安装到展示数据，普通规则/文字模块不预加载大表。运行时全场景最多10个活跃池、每帧最多64次创建；其他卡面保留回退，释放后可继续补位。这是候选工程上界，不是官方允许控件数或已测性能。
