## Description

Milestone: M4｜前两幕首局UI、输入、音画与性能

### 战斗背景生产决策（2026-10-27 已定；2026-10-30 纳入 M4）

- **优先官方原生场景**：开场与前两幕战斗采用千星奇域允许使用的原生 3D 遗迹模型、环境/天空及固定镜头，不新画整屏背景作为首发依赖。复用 TASK-2.1 已有遗迹布景候选，由 TASK-4.2 负责第一幕背景显露、遮罩与场景切换，TASK-4 统筹两幕完整画面和设备验收；不得重复造模。
- **控制 UI 开销**：不采用整屏 PNG→大量 UI 图元（Lua/GIA）拟合路线；官方可直接用的整幅 2D 背景图及原生位图通道尚无确认，不得假设存在。仅在合法可用素材/平台通道与同屏性能得到实证、用户明确改判后再评估 2D 整图；少量局部装饰需控制预算。
- **先实机再扩产**：先检查不透明 backdrop 是否遮蔽 3D，再核实镜头、人物/敌人可读性、地面脚高、遮挡、环境光与场景退出清理；普通/精英/Boss用轻量场景差异化。记录同一候选 PC 与实体手机的空场/布景对照、帧耗时、输入响应和视觉截图；离线构建不等于实机通过，AC 未核实不得勾选。
