## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
防御、能力和群攻等无目标牌拖到战场有效区域松手立即出牌。第一次点牌选中，再点原牌取消；备用操作是在选牌后点明确出牌区域。指定目标牌拖到合法敌人或选牌后点敌人执行。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 不需要选敌人的牌，拖到战场空地松手就出，不用第二次点击。
- [x] #2 能看清哪里可以出牌；松在手牌区或无效位置会取消，不误点其他按钮。
- [x] #3 需要目标的牌拖到合法敌人才能出，松在空地不能替玩家随便选敌人。
- [x] #4 一次拖动只出一次；费用不足或当前不能出牌时，不扣费用也不丢牌。
- [ ] #5 电脑鼠标和手机触摸都测过，并保留点选出牌的备用方式。
- [ ] #6 记录游戏里的实际操作结果；做不到的说明原因，不能把点选可用当成拖牌已完成。
- [x] #7 连续点击同一张牌两次只取消选中，不出牌；无目标牌点选后仅在明确战场出牌区确认。
<!-- AC:END -->
