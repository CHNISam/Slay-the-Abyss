## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 不需要选敌人的牌，拖到战场有效空地松手就出，不用第二次点击。
- [x] #2 一次拖动只出一次；费用不足或当前不能出牌时，不扣费用也不丢牌。
- [ ] #3 电脑鼠标和手机触摸都测过，并保留点选出牌的备用方式。
- [x] #4 记录游戏里的实际操作结果；做不到的说明原因，不能把点选可用当成拖牌已完成。
- [x] #5 连续点击同一张牌两次只取消选中，不出牌；无目标牌点选后仅在明确战场出牌区确认。
- [x] #6 同一副本实测按住拖动和松手跟随，卡牌不突然跳到其他手牌上。
- [x] #7 同一副本实测回到手牌区取消后，不保留选中或响应旧触点。
- [ ] #8 手机拖动无效释放时回手并清除选中、引导线和准星；点选备用保留。
- [ ] #9 手机有效与无效释放各快速和慢速连续20次，记录实体设备同候选结果。
- [ ] #10 手机实际拖动后在无效区、手牌区或屏幕外释放须取消并回手，清除选中、引导线和准星；点选备用保留。
- [ ] #11 PC鼠标按既有交互规则验证有效释放、取消和目标选择；记录新候选结果，不把手机反馈当作PC复现。
- [ ] #12 IMG_1168/1169/1175对应的手机拖动从按下到瞄准无突跳；视觉交互锚点、预览和松手命中一致，多敌人不得空地猜最近目标，记录同候选轨迹与事件。
- [ ] #13 保留点选后备、双击取消和长按关键词；去除贯穿战场的常驻阈值横线与冗余操作提示后，合法目标/取消仍清楚，旧触点不重复出牌。
<!-- AC:END -->
