## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 不需要选敌人的牌，拖到战场有效空地松手就出，不用第二次点击。
- [x] #2 出牌线清晰；无目标牌短拖保留选牌、长拖无效释放取消；目标模式向下拉过原版取消线可取消。
- [x] #3 目标牌只在明确选中合法敌人时出牌；松在空地保留选敌，不自动选择敌人。
- [x] #4 一次拖动只出一次；费用不足或当前不能出牌时，不扣费用也不丢牌。
- [ ] #5 电脑鼠标和手机触摸都测过，并保留点选出牌的备用方式。
- [x] #6 记录游戏里的实际操作结果；做不到的说明原因，不能把点选可用当成拖牌已完成。
- [x] #7 连续点击同一张牌两次只取消选中，不出牌；无目标牌点选后仅在明确战场出牌区确认。
<!-- AC:END -->
