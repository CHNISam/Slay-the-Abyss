## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
进入《杀戮原塔2》时，应看到符合岩系封印遗迹世界观的高塔或遗迹远景；第一幕普通、精英和Boss战应有真正可见的环境背景，避免大片无内容的黑色画布。优先复用已有官方遗迹模型和环境配置，保持角色、敌人、卡牌、血量和意图清楚可读，不重复制作同一批模型。本项为M4首发必做品质切片。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 开场有背景：开始及重新开始菜单有清楚可见的高塔或封印遗迹远景，标题、启程及已有操作不被遮挡；不能以单色全屏代替，不新增按钮。
- [ ] #2 普通战斗有场景：真实客户端可见地面、纵深和远处布景；大面积黑色空场的原因已定位并修复，角色和敌人站位、镜头及UI叠层正确。
- [ ] #3 精英和Boss有识别度：通过可见构图、布景或环境氛围区别于普通战斗，不只换敌人头像，不改变数值、伤害和敌方AI。
- [ ] #4 复用现有成果：基于TASK-2.1官方遗迹资产逐项核实导入、朝向、脚高、遮挡、碰撞和去重，不以离线GIA构建成功代替游戏显示。
- [ ] #5 界面切换正确：菜单、地图、战斗、奖励回图、胜败和重开间背景、遮罩及控件层序一致，无黑屏、残影、穿透点击和旧场景残留。
- [ ] #6 设备与性能合格：留电脑实机及手机目标画布对照截图并检查安全区；同版本同设备对比空场景与布景版性能、输入响应，手机真实设备未测须保持待验，编辑器预览不能代替。
- [ ] #7 同版本证据齐全：保留源码SHA、候选身份、静态检查、官方导入读回、实机截图日志、设备、视觉差异和用户审阅结果，通过项目verify:ui及M4门禁；未经证明的项保持待验。
- [ ] #8 单独提交开场及战斗2D背景插画的技术与美术方案，经用户审阅决定采用或不采用；批准前不批量制作，3D景片不冒充2D插画交付。
- [ ] #9 若批准采用2D背景，本任务负责人完成素材到正式界面、平台导入和同版本实机显示的闭环；若不采用，保存用户决定并明确3D方案的验收边界。
<!-- AC:END -->
