## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
以后有余力再做一次小范围双人测试，确认合作玩法是否可行。这个任务不等于完整联机，也不挡首发。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 两个真实玩家能一起进入并各自操作同一场战斗，保存两端试玩记录。
- [ ] #2 双方看到的状态一致，延迟、重复或乱序操作不会把游戏弄乱。
- [ ] #3 明确双方卡组、手牌、能量和血量归谁，敌人、地图和回合如何共享，并实际试过。
- [ ] #4 有人掉线或退出时有清楚处理，另一方界面能恢复；不能重连就说明。
- [ ] #5 在约定时间内给出能不能做、成本和风险的结论；不提前改正式单人玩法。
<!-- AC:END -->
