# 版本与研发顺序

## 现在：先做好旅行者

当前比赛版本只做**岩系旅行者的第一幕和第二幕**。先完成玩法、批准稿界面与演出、电脑和手机实测，再冻结候选并准备人工投稿。开发力量集中在这一版本。

## 下一版本：再做雷电将军

旅行者版本完成并验收后，再单独启动雷电将军版本的规划、开发和验收。已有 V4 卡包和资产保留，当前不并行推进雷电将军功能、美术或发布；具体范围和日期届时确定。

## 更远的候选

其他角色、第三幕、隐藏第四幕、跨局存档和成就等都不是当前比赛必做，后续根据平台能力和实际资源再安排。

## 现有版本记录

v0.11.0 是当前源码候选，尚未冻结、打 Tag 或发布。v0.1.0 至 v0.10.1 的 Tag 是源码检查点，不代表平台曾发布。完整版本历史见 [源码版本记录](https://github.com/CHNISam/Slay-the-Abyss/blob/develop/docs/versions/README.md)。
