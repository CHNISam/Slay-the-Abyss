# 版本与研发顺序

## 当前唯一研发执行顺序（2026-11-03）

1. **M7｜工程架构与性能强化（m-7）**：先清除架构和吞吐瓶颈；M8 的确定性修复可少量并行。
2. **M8｜产品体验与核心特色（m-8）**：M8-A 优先地图、输入、战斗、美术和手机，M8-B 才是经 Owner 选择的差异化角色与 V4 验收（TASK-96、TASK-85）。
