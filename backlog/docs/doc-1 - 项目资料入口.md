# 项目资料入口

从左侧选择模块；先看以下三项：

1. [比赛范围与验收](/documentation/2/)：当前做什么、各阶段怎样验收。
2. [版本与后续规划](/documentation/3/)：比赛候选、下一版本和历史版本。
3. 看板：正在做什么、哪些任务已完成。

## 按模块找资料

- **产品与版本**：项目总览、版本记录。
- **设计与美术**：批准稿、原型、画面、剧情。
- **玩法与规则**：卡牌、敌人、章节和玩法规则。
- **开发与任务**：任务附件、实现方案和计划。
- **测试与证据**：测试记录、实机证据和评审。
- **历史与参考**：旧方案、实验、授权和研究。

文件目录是资料索引；历史资料可能过时。当前范围以比赛范围文档为准，验收以任务中的证据为准。
