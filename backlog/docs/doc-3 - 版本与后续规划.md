# 版本与后续规划

## 当前比赛候选

**v0.11.0 是源码候选，不是已发布版本。** 目标是岩系旅行者的前两幕，完成玩法闭环、批准稿界面与演出、电脑和手机验收后冻结；发布和投稿由人完成。版本索引中较早的两职业描述已被 10/29 范围决定覆盖。

## 未来候选

- **下一版本**：雷电将军，沿用已冻结的 V4 卡包；具体发布日期和验收安排尚未确定。
- **后续研究**：其他职业、第三幕、隐藏第四幕及真结局；恢复范围前需重新安排和验收。
- **平台能力允许时再评估**：退出续玩、跨局进度、成就等；当前不承诺上线时间。
