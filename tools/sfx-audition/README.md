# 音频测试存档

独立存档只用于原生音频试听：游戏内打开后点击「试玩」，选 A1–A8 攻击或 D1–D4 死亡，再点「播放候选」。不需要 CMD 或外部播放器。

有旧版 A/B、音量、六连击、单次死亡演出、攻击接死亡、原生 BGM，以及喜欢/待定/淘汰和评语。界面显示联动的攻击/死亡编号，避免浏览其他候选后误用上一条攻击。新试听从待定开始；评语写入本轮 SFX_REVIEW 客户端日志，退出试玩后保留日志。

本轮选择见 [SFX_SELECTION](../../docs/SFX_SELECTION.md)。A1–A4 为40305/40309/40313/40317，A5–A6 为40221/40224，A7–A8 为51044/51049；D1–D4 为20092/20109/20117/20139。A0/D0 保留旧50936/50941。

初始音量65只是试听起点，不代表响度已匹配。BGM沿用 native-bgm-graph.mjs 的战斗cue；不提取素材，不另做播放器。

开发者重建：`node scripts/build-sfx-audition.mjs <空白底图.gil> <不存在的输出目录>`。使用项目自己的空白底图，不能传正式关卡。工具路径支持 MILIASTRA_MCP_ROOT，Python遵循 docs/TOOLCHAIN.md。生成器只写副本，记录底图hash、Git SHA/dirty状态、控制器hash；不会清理任意底图里的其他图或脚本，输入必须没有游戏逻辑。

回归：`node --test tests/sfx-audition.test.mjs`。编译、副本写入、游戏里实际出声分别验收，回归不代替听感。
