# 准确伤害与整数资源显示

2026-10-24 用户实机截图发现普通攻击显示 `4～6`、`6～9`，节点顶栏生命显示 `68.0/80`。这两项均作为缺陷处理。

## 原因与修正

- PR143 将多个敌人的受伤修正合成最小/最大范围，测试也接受了这一自行增加的显示语义。本轮删除范围：普通手牌只用玩家修正，瞄准后再计算目标修正；群攻保留逐目标计算，显示第一个怪物槽的值。
- 节点界面直接拼接 Lua 浮点数。统一使用有限整数格式，`68.0` 显示 `68`；`68.5` 等真正的小数会报错，不能悄悄四舍五入隐藏结算问题。
- 复核单体、多段、群攻、当前格挡伤害、格挡修正、费用、奖励及节点资源。预览只读，实际结算公式不变。

## 原版核对与防复发

参照固定版本的社区反编译镜像 [AbstractCard](https://github.com/aeubanks/sts/blob/319009d5df0a82d9fb0f23cc22322286c6a87ec0/cards/AbstractCard.java) 的 `applyPowers` / `calculateCardDamage`，以及同版本 `AbstractPlayer.renderHand`。该镜像不是官方开放源码，也不等于官方客户端认证。原文件已保存在本地证据目录，可用文件 hash 复核。

新增回归使用独立字面预期：玩家虚弱时普通攻击手牌 4，瞄准易伤敌人 6，取消恢复 4；检查能量、牌数和随机状态不变。旧版模块运行新断言会失败，避免测试继续认可自创范围。新增整数格式测试拒绝小数、无穷与非数字。
