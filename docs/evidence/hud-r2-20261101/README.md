## 复现与验证

先 `npm run build:data && npm run build:theme && npm run build:ui`。复用现有 Playwright，不安装依赖：

```sh
PLAYWRIGHT_ENTRY=<已有playwright入口> CHROME=<已有chromium路径> node experiments/ui-polish-sim/hud-r2-render.mjs <输出目录>
```

另保留改后首/中/末三张阅读牌1280×720图；独立代码复审检查全部生产及测试diff，无阻断意见；生成战斗树最大直接子控件58，未越原生60上限。

生产 Host 夹具执行真实 Lua；`page.setContent` 渲染自包含 HTML，以免云端 file:// 策略拦截造成 CLI截图超时且缺PNG。捕获自身有30秒Lua、15秒浏览器/页面/截图边界。
