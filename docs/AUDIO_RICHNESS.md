# 音效与音乐补全 · 2026-10-24

用户要求锻造有打铁反馈、地图和每场战斗有音乐，攻击更有力度、死亡和开宝箱更丰富，同时保持适当、不嘈杂。复用TASK-4、TASK-29和TASK-34；不改玩法、随机流、视觉布局或正式存档。

用户随后明确决定先直接采用、不等待试听，并纠正仅按命中轻重配置的遗漏：需要角色/怪物自己的行动声音。最新切片补齐这层后直接接入，不把用户试听作为合入前置；未实机听验仍按事实保留。

## 行动声音与原版资料核对

本轮读取仓库已有社区反编译镜像记录（[固定来源](https://github.com/aeubanks/sts/tree/319009d5df0a82d9fb0f23cc22322286c6a87ec0)）：Cultist在仪式分支有自身发声、攻击分支用斩击效果；Looter两个攻击分支复用自己的发声集合；JawWorm的Bellow有专门吼声，Chomp和Thrash使用各自效果。因此不能写成“原版所有招式都只有同一个角色声音”，也不能仅按伤害轻重推导全部声音。该镜像并非认证正版PC构建，本轮没有原版直接听验。

本项目采用两层：起手时按敌人definitionId播放固定行动声，命中时保留接触/格挡反馈；死亡另外收尾。23个敌人均有固定配置，人形用丘丘人发声候选、兽类用魔兽发声候选、机关用金属动作音；是本项目的官方目录选配，并非搬用原版资产或声称与原版逐动作完全相同。行动声统一放在intent步骤，多段每次行动只播一次，技能/攻击不按伤害值更换该敌人的声线，睡眠、眩晕和逃跑静默。没有使用战斗随机数抽音。

玩家在每张牌起手统一使用40313单手剑动作声，替代通用卡牌UI声，攻击/技能/能力同一出手标识；命中声另在接触帧发生。**当前目录未核实可用的荧战斗人声，40313是动作音，不能冒称角色语音。**

本次修正的是漏掉行动主体发声的设计遗漏；此前测试仅验证命中和死亡，不能发现该缺口。新增生产适配器回归覆盖怪物身份、攻击/非攻击、多段只叫一次、睡眠/眩晕静默和玩家统一出手声；主题构建还强制每位敌人和玩家都有行动音配置，避免再次静默漏项。只在本项目补保护，不增加全局规则。

## 音乐交付

`npm run build:native -- <底图.gil> <新目录>`生成完整游戏和开启BGM的最终副本；读最终`audio/candidate.json`。地图/普通战斗/精英/Boss/胜败沿用原生分场景管理，牌库刷新不重启，结算暂停，重开恢复地图曲。曲目表见[NATIVE_BGM](NATIVE_BGM.md)，普通战斗10044保留历史认可，其余仍待同候选试听，不宣称本轮已精选完成。
