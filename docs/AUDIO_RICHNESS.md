## 音乐交付

`npm run build:native -- <底图.gil> <新目录>`生成完整游戏和开启BGM的最终副本；读最终`audio/candidate.json`。地图/普通战斗/精英/Boss/胜败沿用原生分场景管理，牌库刷新不重启，结算暂停，重开恢复地图曲。曲目表见[NATIVE_BGM](NATIVE_BGM.md)，普通战斗10044保留历史认可，其余仍待同候选试听，不宣称本轮已精选完成。

## 验证与待办

本地节点回归覆盖锻造预览静音、成功单次敲击、继续/刷新静音、休息、开箱与领取两阶段、重复点击和音频异常；战斗回归覆盖重击替代、按怪物类别死亡、群攻单声及既有演出顺序。源码检查、写入副本、官方导入和实际听验分别记录。

最终仍须在同一完整候选听验普通/重击、连续攻击、同时击杀、开箱领奖、锻造，以及地图往返战斗和重开，录制含声音视频。当前Lua的PlayAudio2D接线未提供已核验的单声部音量控制，不能把独立试听版的65音量当作正式混音。若尾音或响度不合适，继续替换官方短音候选；不把增加数量当作听感验收。
