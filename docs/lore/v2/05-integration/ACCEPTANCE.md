# 可验收标准：结果先于实现

## 设计验收（本包目标）

- [x] 世界树能解释玩家进入遗迹的动机。
- [x] 商人、信徒、掠夺者、遗迹守卫、圣职者和生态生物互不混为一谈。
- [x] 七类节点能够承载具体世界观行为，而不是同一种氛围词重复出现。
- [x] 四段用户认可原文逐字保留；辅助文案与原文状态分离。
- [x] 明确 STS 原版事实、GI 通用背景、本作原创及机制未验证项。

## 代码 / UI 验收（**未执行**，由下游 Agent 完成）

- [ ] 开场、Boss、胜、败均完整展示 user_approved_verbatim 文本；没有偷换为 compact。
- [ ] 玩家在开场可正常启程；Boss 出场后可看清生命、意图、费用并操作。
- [ ] 胜败结算显示统计、重新启程、正式结算；叙事不遮挡或阻塞。
- [ ] 商人可见且短反馈与真实购买/不足/离开结果一致；无新增未授权交易功能。
- [ ] 事件三层：情境正文、可用选项/费用/禁用原因、实际结果；失败不会写成成功。
- [ ] 窃金客实际偷金/逃跑/返金由 TASK-15 规则任务单独证实；未实现前不得用 UI 文案冒充已实现。
- [ ] 不修改卡牌/敌人数值、核心随机性、路线、商店概率和奖励数据来迁就叙事。
- [ ] 本地测试回归可追溯到本次源 SHA / 被测文案；不能只跑 JSON 存在性测试。
