# 旧路商人（暂定称呼）

## 身份与功能

- 一名在遗迹中经营交易的老人；来历留白，**不是已证实的祈火徒成员**。
- 逐利、随和、精明，有对危险道路的经验；有点神秘，但不负责解释整座遗迹的历史。
- 交易内容必须和游戏既有商店 UI/运行时供货能力一致。当前商店卡牌、遗物及移牌服务已存在；不要凭文案先声称新增可买药水。
- 视觉建议：旧毯子、木箱、简陋货架、老人半身/剪影；避免使用原作原角色造型素材。

## 入场（辅助文案，v2 暂定）

> 转过一道石廊，荧看到一块旧毯子，上面摆着卷册和古物。毯子后坐着一位老人，像是早就知道会有客人来到这里。

## 五条短对白（v2 暂定）

| 触发 | 文字 |
|---|---|
| 欢迎 | 「路不好走吧？来，看看有没有用得上的。」 |
| 购买成功 | 「眼光不错。」 |
| 金币不足 | 「这可不够啊，小姑娘。」 |
| 询问来历 | 「做生意嘛，总得知道哪条路安全。」 |
| 离开 | 「前面可不像这里太平。一路小心。」 |

## 最低落地体验

1. 商人至少能以符合原有美术规范的视觉元素 **被看见**；实现前先核平台可用资产、控件预算和现有批准原型，不重做商店。
2. 进入、买到、买不起、离开分别只触发一条短反馈；不能盖住商品价格、效果、拒绝原因。
3. 不新增“询问来历”按钮，除非用户另行批准真正的对话功能；这句可作为非交互式随机闲谈备选。
4. 不增加商人的隐藏真相或奖励系统。

## 世界关系

- 和盗贼不是必然同伙；遇到劫掠者并不说明商人背后是同一势力。
- 他知道危险通路但不披露如何往返，这种留白可以不填。
