# 祈火徒

## 概念（本作原创，不是原作鸟类宗教设定）

- 起源：部分滞留遗迹的人害怕越来越浓重的黑暗，将火焰视作庇护与力量。
- 仪式：低声祈祷、聚火，随后自身攻击能力增长；与现有 `cultist` 的 Ritual 设计形成统一解释。
- 变化：一部分信徒因长期侵蚀变得狂热，对陌生来客抱敌意。
- 关系：不为 Boss 工作，不统领洞窟生物；教派完整架构、教主、最终目的都不擅自确定。

## 遭遇文案（v2 暂定）

> 火光映在岩壁上。一名披着灰袍的人正在低声祈祷，手中的火焰随着祷词愈发明亮。察觉到荧的脚步，他缓缓转过身来。

## 行为与叙事的对应

- 首动仪式增益、后续进攻：角色确实在利用某种祈祷力量，不能仅在文字里自称信徒。
- 暂不要求新增『信徒大会』事件，也不要将原版第二幕 The Nest 生搬至本作第一幕。
- 未来出现更多信徒相关遗物/事件时，可以从这里扩展，但必须以实际玩法、概率、来源门禁独立验收。
