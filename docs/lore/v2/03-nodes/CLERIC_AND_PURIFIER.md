# 两个现有随机事件的叙事草案

> **这不是增加新事件。** 仓库当前已经有 `cleric` 与 `purifier` 的运行时事件；具体操作、费用和条件以当时最新版 `src/lua/abyss_nodes.lua`、`data/rules.json` 和 TASK-13.1 为唯一规则来源。

## A. 圣职者（Cleric）

**开场（v2 暂定）**

> 一位披着长袍的陌生人拦住了去路。

「哎呀，旅行者！伤口要治吗？或者有什么不想再带着的招式？我都能帮上忙。」

他笑着指了指身旁的价目表。

「当然，得收一点金币。」

**选择树**

```text
圣职者
├── 治疗：支付游戏当前实际治疗费用 → 回血 → 显示新生命值
├── 净化：支付游戏当前实际费用 → 选择要移除的卡 → 删除并确认
└── 离开：不发生交易 → 继续前行
```

**关键一致性**：不要给没有足够金币的选项写“已经完成”；不能通过额外剧情绕开数值限制。

## B. 净化神龛（Purifier）

**开场（v2 暂定）**

> 破损的石龛静静立在路旁，表面的古老纹路仍散发着微光。

当荧靠近时，一股平静的力量从中传来，仿佛能够让人放下一些不再需要的战斗方式。

**选择树**

```text
净化神龛
├── 祈祷：免费选择一张实际可移除的卡 → 删除 → 显示结果
└── 离开：不改变持有物 → 继续前行
```

## 显示约定

- 事件屏应有 **正文**、**选项名称/成本/限制**、**执行结果** 三层；不能全部压缩成一行操作说明。
- 结果文字应基于实际返回值，且操作失败要有原因；成功不再重复扣费/删卡。
- 借鉴 STS 事件的“情境→选择→后果”结构，但不用原作中文原文或素材。
- 不改现有本地逻辑和概率，玩法差异交 TASK-13.1 核查。
