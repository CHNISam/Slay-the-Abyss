# 七类节点叙事树

```text
一局探索中的七类节点
├── 普通战斗：来自不同动机的敌人（身份要与招式一致）
├── 精英：危险魔物或防御系统的更强威胁
├── 营地：危险旅途中短暂的休整空间（休息 / 升级）
├── 商店：旧路商人经营交换（商品 / 价格 / 移牌）
├── 未知事件：人物与神龛、选择与代价（现有 Cleric / Purifier）
├── 宝箱：旧文明的物资与遗物（开箱 / 奖励）
└── Boss：封印守卫的身份反转与结局
```

| 节点 | 玩家真正应接收到什么 | 注意 |
|---|---|---|
| 普通战斗 | 眼前是怎样的敌人；敌人行为与身份相符 | 不给每场杂兵加长对白 |
| 精英 | 更危险的敌人类型，有个体特点 | 不能靠故事字句替代原版 AI/数值 |
| 营地 | 被允许暂时休息，选择回血或升级 | 操作/收益显示优先 |
| 商店 | 能看到行商老人、商品与售价，听到短反馈 | 价格、购买条件、库存永远清晰 |
| 未知事件 | 遇到谁/什么、为何要选择、代价与结果 | 保留具体事件正文、选项、状态 |
| 宝箱 | 箱中保存了什么、有明确领取结果 | 不引入无依据额外奖励 |
| Boss | 明白守卫的原本职责和当前异变 | 避免抢占 HP/意图/出牌操作 |

**不要以『岩光闪烁』『幽暗的回廊』统一填充所有节点。** 场景气氛不能代替人物、经济、信仰和事件。
