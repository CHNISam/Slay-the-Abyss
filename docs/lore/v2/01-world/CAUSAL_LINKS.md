# 设定因果与一致性

## 为什么这些事会同时发生？

```text
原本存在封印的古代遗迹
  ├─ 旧防御机关继续值守 → 哨卫、沉眠遗卫、深渊守卫
  ├─ 地脉失序 → 路线与生物活动异常（地图随机性的叙事解释）
  ├─ 暂未被彻底毁坏的通路与物资 → 行商交易、遗迹宝箱、暂时营地
  ├─ 出入遗迹的人群 → 探索者、圣职者、劫掠者
  └─ 面对黑暗而产生的仪式信仰 → 祈火徒
                     ↓
     旅行者为调查封印异变进入遗迹，与不同动机者遭遇
```

## 不允许偷换的关系

- **守卫 ≠ 深渊教团干部**：守卫是封印的保护者，因侵蚀变得无法辨别敌友。
- **商人 ≠ 祈火徒**：老人经营交易、知晓道路；他如何存活与进出留白。
- **掠夺者 ≠ 被 Boss 派遣**：偷钱动机就是劫掠，不需要阴谋统领。
- **祈火徒 ≠ 所有魔物共同主人**：只是遗迹里的一支信仰群体。
- **营地安全 ≠ 绝对无风险地带**：用于休息/升级的游戏节点，无需把地图变成永久安全区域。
- **卡牌 ≠ 每张实体纸牌由荧掏出来扔**：卡组是一种战斗系统抽象，可表现为技艺和记忆。
- **随机地图 ≠ 要实装时间循环剧情**：地脉失序只作为路线变化的叙事理由。

## 给场景与美术的最低信息

- 背景：岩石古迹、残存符文、少量异常侵蚀；不要全场景铺满同样的蓝紫特效。
- 商店：旧毯子、木箱、货物、老人剪影，展示人为活动痕迹。
- 信徒：火光、仪式姿态，强调与守卫不同的社会身份。
- 守卫：古代机关、保护封印的功能性设计；深渊侵蚀为后来发生的变化。
- 与 GI 官方可使用的模型/场景资产结合时，按仓库现有美术产线和平台能力验证；本包没有生成任何视觉资产。
