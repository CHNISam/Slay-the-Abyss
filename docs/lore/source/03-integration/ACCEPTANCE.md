## 三类证据清晰分开

1. **静态/本地**：JSON 可解析、引用正确、原有测试/检查通过，显示文案的快照或预览截图。
2. **平台构建/导入**：千星客户端或对应副本的真实构建与导入结果，保留版本/hash和日志。
3. **实机**：实际菜单、胜/败界面截图及操作，确保文字不截断、不挡按钮；未实测就标未实测。
