# 《原神》设定与原创设定边界

本页防止 Agent 把原创提案写成米哈游已经确认的原作事实。

| 概念 | 可如何使用 | 不应该怎么写 |
| --- | --- | --- |
| 旅行者荧 / 岩元素 | 现有项目主角与属性 | 改成原创主角或别的元素 |
| 璃月、地脉、深渊侵蚀 | 作为原神语境里已有的大概念和灵感 | 虚构一个原作已确认的“璃月某封印遗迹官方任务” |
| 岩脉残响、古老遗迹、封印 | **本作品的原创设定** | 声称出自官方主线、深境螺旋或特定世界任务 |
| 深渊守卫 | 游戏内现有 Boss 名称和原创背景 | 混淆成原神已存在的同名官方角色/深渊教团成员 |
| 重复开局 / 变化的地图 | 失序地脉是**氛围解释** | 承诺时间回溯或机制性的无限轮回系统 |
| 古代机关 / 商人 / 神龛 | 与当前 UI/事件对应时可用 | 添加不存在的 NPC、能力、交互、分支奖励 |

- **不要强行绑定坎瑞亚、天理、戴因斯雷布、七神秘史等复杂主线解释**。首发只要局部、完整、自洽。
- 不刻意引入高密度的官方专有名词，以免破坏玩家理解和真实性。
- 不把《杀戮尖塔》的剧情、原始角色立绘、文案、怪物官方设定或其他人的存档直接照搬；玩法保留参照基础，叙事与呈现用自己的写法。
- 如果将来需要让文本与官方 lore 更精确对齐，再单独做考据；**当前包不是官方 lore 权威档案**。
