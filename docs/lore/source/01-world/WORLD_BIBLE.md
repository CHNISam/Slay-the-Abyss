# 世界观：岩脉残响

## 一句话概念

旅行者荧在璃月群山深处感知到岩元素异常，进入地脉失序的古老遗迹，历经各类抉择与战斗，击败受到侵蚀的守卫并修复封印。

## 背景（用户已认可方向的原文，不是必须一次在 UI 全部显示）

> 璃月群山深处，一座被遗忘的古代遗迹突然出现了异常。
>
> 封印正在崩解，深渊的力量顺着地脉裂隙不断蔓延。沉睡的守卫重新苏醒，魔物的残影徘徊于破碎的回廊。
>
> 旅行者荧循着岩元素的共鸣来到这里。为了阻止侵蚀继续扩散，她必须深入遗迹，找到异变的源头。
>
> 然而，遗迹内部的道路早已被混乱的地脉扭曲，每次进入，都可能面对不同的命运。

## 叙事骨架

| 环节 | 发生什么 | 玩家为何在意 |
| --- | --- | --- |
| 启程 | 封印异常，荧进入遗迹 | 此次冒险的理由 |
| 探索 | 失序地脉使路线重组；怪物、遗物、商人、营地散落其间 | 为什么每局选路、刷牌不同 |
| 危机 | 深入遗迹后，古代防御机制和侵蚀愈发明显 | 精英与 Boss 的威胁有因果 |
| Boss | 「深渊守卫」原是看守封印者，现受侵蚀而无法辨识来客 | 战斗具有目的与一点情绪反差 |
| 胜利 | 修复封印，侵蚀暂退；旅行者继续旅途 | 给一局一个完整句号 |
| 失败 | 探索中断，封印仍不稳定；玩家可重新开始 | 失败与重开不要求特殊时间循环系统 |

## 七种节点的同一世界观解释

- 普通战斗：受侵蚀的魔物、失控机关或敌对残影挡路；不把所有现存怪物硬称“深渊教团”。
- 精英：更强的地脉异变、古代防御体或深层威胁。
- 营地：安全的残存庇护所；休息/锻造仍按原有玩法。
- 商店：在危险之地交易的神秘旅人；不新加人物对话系统。
- 未知事件：旧石碑、神龛、异乡人或偶遇；实际内容必须与当前事件数据一致。
- 宝箱：古代遗迹残存补给或遗物。
- Boss：原封印守卫受侵蚀，打败后裂隙重获稳定。

## 风格

**关键词**：幽深、孤独探险、岩元素、残光、古文明、破败但不恐怖、克制的希望。

**声音口吻**：接近《原神》探索文本——短、含蓄、有画面。不是长篇设定解说，也不写显得深奥但不可理解的谜语。

**叙事密度**：玩家打开游戏可迅速开始；流程不被文本打断。长背景留在物料/说明页，游戏中只显示几句提示。
