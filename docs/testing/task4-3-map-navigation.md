# 地图查看按钮与滚动体验：离线交付

对应TASK-4.3，属于M4的小范围呈现优化。按PR19批准稿、UI_DESIGN与共享主题实施；地图生成、节点位置、连线、可达性与选路规则文件没有修改。

## 行为

- 上下按钮始终在原位置显示。到0/maxScroll边界时使用现有line/textMuted颜色，命中区隐藏且不能获得控制器焦点；即使旧回调被直接调用也不会越界。
- 上下按钮与“当前进度”使用主题motion.base的0.2秒三次ease-out，起点为实际显示位置。同方向连续点击累计已限界的目标；反向点击从当前画面重新单步定位，立即反向且不瞬移，相同目标不重启动画。自动进入地图/选路后的定位仍即时，保留原协调器约定。
- 步长从3层228px改为主题layout.map.scrollStepFloors=2，即152px，占600px视窗约25.3%（原38%），保留更多上下文重叠。floorGap、节点坐标与视窗边界不变，实际舒适度仍待实机。
- 指针按下立即终止未完成动画，从当前显示位置直接跟手。滚动中暂不接受节点点击；接管动画的那次手势不借用旧节点选择，必须新鲜点击才能选路。保留原拖动阈值、触点归属、过期手势与导航事务约束。
- 隐藏、缩放、换图、外部地图进度变化、直接滚动及减少动效均终止旧动画；减少动效时即时定位。复用现有按钮面层、颜色、0.96按压比例和Cursor事件，取消/离开/重绘/缩放复位，触屏不残留悬停。
- 不增加控件、计时器、依赖或后台循环。缓动只使用已有OnUpdate，静止后不额外渲染地图；没有做真实设备帧率测量。
