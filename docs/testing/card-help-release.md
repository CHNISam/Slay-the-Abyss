## 复现与最小修正

Bash 按下 50ms 后松手并点选，继续等待 310ms，再首次点敌人：旧实现仍把已松开的按下当成长按，弹出关键词帮助并吞掉目标点按。敌人生命仍为 52、能量 3、手牌 3。

帮助计时现在绑定卡牌的现有输入令牌。仅同一输入及触点的 Up/EndDrag 取消该令牌的帮助；更新时确认令牌仍被持有、卡牌 UID 与战斗/回合仍有效。普通悬停及非卡牌帮助不绑定该令牌，旧释放不会清掉后来出现的有效帮助。

修后首次目标点按正确打出一次 Bash：敌人生命 44、能量 1、手牌 2。没有修改伤害、费用、规则、主题、布局、状态面板滚动或播放缓存；保留分裂说明使用实际子敌人的名称。
