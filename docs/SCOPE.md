# Slay the Abyss · 首发范围与削减优先级

对标：初代《杀戮尖塔》第一幕，以原神千星奇域（Miliastra Wonderland）实现。
硬线：**2026-10-30 完成发布准备并由人投稿**（官方截止 2026-11-02 11:59 UTC+8）。

## 本次参赛角色

- 主角固定为《原神》的荧（Lumine），只做风元素形态。
- 卡牌表达围绕单手剑、风涡与风息；“战士”仅指当前数值参照，不是角色身份。
- 其他元素留后续版本。卡牌化改编不等于原神技能原样移植；未实现的牵引、扩散和元素转化不得写成已有功能。

## 必须保留的闭环（缺一不可）

1. 回合制卡牌战斗：抽牌/弃牌/能量/伤害/格挡/敌人意图/状态效果
2. 15 层分支地图 + 7 类节点（普通战斗、精英、营地、商店、未知事件、宝箱、Boss）
3. 营地：回血 或 升级卡牌
4. 商店：购买卡牌/遗物、删除卡牌
5. 战后奖励、遗物、金币、药水、卡牌升级、跨节点状态**真正生效**
6. Boss 战后正式结算；失败可重新开始

## 削减顺序（时间不足时从上往下砍）

1. 第二角色及其他元素（本次只做风元素荧）
2. 第二章节
3. 额外 Boss（首发只做 1 个）
4. 装饰性系统（皮肤、成就、排行榜等）
5. 过多卡牌变体（战士 75 张是完整对标目标，首轮保 30+ 可用构筑）

**不能砍**：卡牌构筑、分支地图、商店、营地、Boss 闭环。只有两个敌人的技术测试不算正式作品。

**明确状态保存边界（对应 TASK-14）**：首发必须保证同一局 15 层之间卡组、血量、金币、遗物、药水等状态正确保持；不要求玩家退出关卡后下次进来续上次的局。后者是官方奇匠 Lv.4 才解锁的「局内存档」，可延后，不得误认为 M2 必须等 Lv.4 才能执行。

## 内容规模标杆

- 普通遭遇：约 14 种组合
- 普通敌人变体：19 种
- 精英：3 种
- Boss：首发 1 个
- 战士卡牌：完整对标 75 张，首轮先做核心 30+

## 数值与资产原则

- 复用成熟规则与有来源的基础数值，以数据驱动方式实现，不从零设计整套平衡。
- 复用原神官方允许使用的资产；代码、卡牌文案、美术自己实现。
- **不得搬运其他创作者的资产与存档。**

## 报告纪律

- 编译通过 / 写进存档 / 游戏里真的验证过，三件事分开报告。
- 内容缺口必须如实报告，不得把未完成功能宣布为通过。
- 官方允许最多投稿 2 件，已投稿作品不可更换；先完成第一件，第二件只在确有完整作品且时间允许时考虑。
- 发布与赛事报名由人完成，Agent 不得虚报投稿成功。
