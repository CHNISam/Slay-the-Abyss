# 杀戮原塔2 · 首发范围与削减优先级

正式名称：**杀戮原塔2**（用户于 2026-10-24 确认，原名《杀戮深渊》）。本次为作品更名，名称中的“2”不改变下述初代《杀戮尖塔》的规则对标与首发范围。

对标：**初代《杀戮尖塔》PC 正式版 Ascension 0 的数值、机制、敌人AI、随机规则与战斗反馈时序**，以原神千星奇域（Miliastra Wonderland）独立实现；不引入二代或自创平衡。详见 [RULE_PARITY.md](RULE_PARITY.md)。
硬线：**2026-10-30 完成发布准备并由人投稿**（官方截止 2026-11-02 11:59 UTC+8）。

## 本次参赛角色

- **首发**为《原神》的荧（Lumine），**岩元素形态＝初代 Ironclad 战士的职业规则包**；逐项使用该职业的初始牌组、遗物、卡池、费用、升级、战斗算法与数值。岩元素是人物/演出身份，而不是自行创造属性反应或加减数值。
- **不同元素承接不同职业规则包**：风＝Silent（毒/飞刀/弃牌）、雷＝Defect（充能球/集中）、草＝Watcher（姿态/占卜），均为**拟议映射，尚未决定要在本次比赛实施**。每种元素内可保留原职业的多种合法构筑；绝不把战士牌简单换色后称为新流派。
- 单手剑、岩系星陨剑等原神视觉、名称和世界观可包装原作卡牌效果；不额外赋予原作没有的攻击、元素反应、护盾或状态结算。原版相关数值/概率/触发顺序不可更改；未实现的效果不能放入合法可玩池。

## 必须保留的闭环（缺一不可）

1. 回合制卡牌战斗：抽牌/弃牌/能量/伤害/格挡/敌人意图/状态效果

3. 营地：回血 或 升级卡牌
4. 商店：购买卡牌/遗物、删除卡牌
5. 战后奖励、遗物、金币、药水、卡牌升级、跨节点状态**真正生效**
6. Boss 战后正式结算；失败可重新开始

## 削减顺序（时间不足时从上往下砍）

1. 第二元素及对应新职业规则包（本次先保证岩元素荧）

**明确状态保存边界（对应 TASK-14）**：首发必须保证同一局第一幕各节点之间卡组、血量、金币、遗物、药水等状态正确保持；不要求玩家退出关卡后下次进来续上次的局。后者是官方奇匠 Lv.4 才解锁的「局内存档」，可延后，不得误认为 M2 必须等 Lv.4 才能执行。
