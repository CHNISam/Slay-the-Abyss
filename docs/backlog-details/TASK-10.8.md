# 行动意图与状态说明修复

2026-10-24 用户实机把头上的“脆弱 1”理解成敌人持有状态。随后截图证明已有状态说明面板存在，但只有图标和正文可见，标题、状态名和层数缺失。

## 已实现的修正

- 敌人头上只给攻击显示伤害数字；非攻击意图不再把预期状态层数当成头顶数字。意图说明写明下一次行动尚未执行；已有状态仍读取实际承受者。
- 说明标题、摘要、状态名采用原生文字最小 40 高框，避免 22/28 高短框裁切。单项显示名称、层数、增减益及效果。
- 每个状态图标与意图增加鼠标悬停、350ms 长按和点按入口，卡牌悬停解释关键词。复用批准稿主题与现有说明面板；没有新增独立教程或视觉方向。
- 说明只读，输入绑定当前战斗、回合和角色实例；离开战斗取消待显示说明。长按释放不出牌、不改目标，不允许旧敌人或其他手指接管触点。

## 平台差异与剩余验证

面板最多同时列三行，超出明确提示；可分别查看图标。原生鼠标进入/离开、触屏长按、44 大小热区和真实字体仍须新候选实测，不能用控件替身测试宣称平台通过。完整 UI 门禁未通过。
