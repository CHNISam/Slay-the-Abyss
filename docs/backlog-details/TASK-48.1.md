# TASK-48.1｜筑星训练营地任务与赛后迭代

## 为什么纳入 Backlog

2026-10-29 用户确认：比赛投稿不是项目终点。《杀戮原塔2》还要继续更新；官方训练营提供的玩家试玩反馈、平台流量扶持和可能的创作票券收入值得争取。关联长期运营父任务 TASK-48，但这是有明确解锁顺序与截止窗口的独立活动，不等同于直播推广。

**优先级：Low，非当前首发阻塞。** 保留 TASK-6（正式发布报名）及 TASK-20（版本/凭证）现有工作，不修改 M3–M6 目标、截止日、游戏代码或发版流程。由 Furinya 在官方账号中完成报名、投稿、共创与评审；自动化 Agent 只能整理材料、核对证据，不冒充人工提交。

## 官方活动的五个阶段（依页面规则）

| 阶段 | 任务 | 前置和时间要求 | 留证 |
| --- | --- | --- | --- |
| 1 | 撰写关卡创意企划书 | 官方页面提示审核预计 **7 天**；以实际结果为准 | 报名时间、企划提交、审核结果 |
| 2 | 制作并发布关卡 | 任务2解锁后按页面提交。**关卡首次发布时间必须晚于训练营报名时间**；原文并未要求首次发布时间晚于任务2解锁 | 关卡 ID/GUID、首次公开发布时间、任务2提交/结果 |
| 3 | 参与「奇域共创计划」 | **邀请时间晚于任务3解锁时间**；对任务2关卡发起1次邀请并收到玩家反馈才可解锁任务4。额外1次共创邀请次数预计在解锁任务3后2天内发放 | 解锁时间、邀请时间、玩家反馈原始记录 |
| 4 | 完成一次关卡调优 | 根据任务3反馈完成真实改进；**最近更新发布时间晚于任务4解锁时间** | 改进内容、前后差异、最近更新发布时间、任务4提交结果 |
| 5 | 提交「关卡质量评审」 | 关卡打磨到合适状态后提交，等待实际审核 | 评审提交、结果、后续改进结论 |

- **同一关卡的 Alpha→v1.0 更新不等于首次发布。** 正式版能否作为任务2关卡，关键看实际关卡 GUID 的**首次公开发布时间**是否晚于报名；若 Alpha 曾在报名前以相同 GUID 正式公开，需要先核实资格，不能通过修改版本号规避。
- 训练营活动页面在 2026-10-29 显示总期 **60 天、剩余 59 天**。这是用户当日界面快照，**不擅自推算确切截止日**，以后以账号页面显示的实际截止和任务状态为准。
- 用户看到的激励为 **30 一号创作票券及流量激励**。金额换算、领取资格、发放及提现以当时官方有效规则和实际到账为准；不要把计划奖励计为已获得收入或保证曝光。
- 任务3/4具有**解锁后**的时间门槛；不能拿先前已有的试玩、邀请、更新去冒充解锁后的完成记录。
- 优先复用已有作品、正式物料及发布记录，**不为训练营新造一套作品或未经批准替换比赛投稿对象**。确需另发关卡时，先核官方活动/赛事规则并由用户决定。
- 完成或错过活动都记实际结果及原因；记录可见的曝光、试玩、用户反馈与据此完成的产品修复。反馈有实质问题时复用既有 Backlog 任务或查重后建立，不重复记账。
