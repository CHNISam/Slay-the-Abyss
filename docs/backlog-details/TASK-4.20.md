# 手机文字可读性修复

用户反馈手机文字很小，顶部资源行尤其难读，年轻玩家也看得费劲。该反馈按阅读障碍处理，不推断玩家视力、年龄或设备性能。

## 已确认的问题

基线为 develop `2d06741de47f2a65eb2772705e33064c16ccdce3`。主题正文18、标签16、最小14；原生文本启用自动适配并允许回落14。卡组入口数字框只有20×14；退出提示的多行框也不足。stage按1280×720等比缩放，手机可能仍返回同样的UI画布，不能据画布宽度识别手机，更不能将设计字号直接称作pt/dp。

## 修复决定

直接提高默认正文、标签、提示和关键资源数字的字号，同步扩大或重排容器；关键文本不再自动缩回旧字号。沿用现有深底金色主题与控件，背景按Owner决定留待下版本。单纯放大整个stage会裁切；只提高字体而不改容器会挤压信息，均不采用。卡牌小面与完整阅读入口单列核验，保留所有卡牌名、数值和原有交互。

实施计划以Backlog TASK-4.20为准：先固定失败断言，再改主题及受影响布局；验证最长数字、长中文、两幕各页面、弹层和可见入口；检查普通重要文字在确定背景上的对比度，最后独立审查、当前提交完整CI与正常develop合并。

## 无障碍依据与验收边界

- [Game Accessibility Guidelines：易读默认字号](https://gameaccessibilityguidelines.com/use-an-easily-readable-default-font-size/)：默认文字应足够大，可选择字号是更完整的方案。
- [WCAG 2.2 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通文字对比度参考4.5:1；不把引擎设计字号套成大字豁免。
- [WCAG 2.2 1.4.4](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)：文字可放大200%且不丢内容/功能。默认字号增大不等于已满足此条。

源码和离线渲染只证明布局与配色策略。当前未接官方编辑器或实体手机，实际字体单位、阅读距离、字体放大与原生裁切须同候选实测；不宣称完整WCAG AA认证或手机验收通过。
