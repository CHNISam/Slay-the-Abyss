## 根因与修复

- `canViewRoute` 只判断已有地图，地图模式仍可再次打开同一地图。现在可见性、触控和手柄命令统一拒绝地图模式；菜单原有收起空行逻辑继续使用。
- `closeExit` 的路线分支只关预览，保留父菜单。现在关闭预览后继续原有完整菜单关闭路径，一次返回恢复原战斗或节点。保留 `exitGeneration` 递增、只读预览和既有刷新流程。
