# 手机卡顿与加载路径调查

同一批用户反馈包含“很卡”，未提供发生阶段。加载慢、手机配置不足均不是已确认根因。保持背景现状，不启动已延期的背景图元优化项目。

基线 develop `2d06741de47f2a65eb2772705e33064c16ccdce3` 的独立离线探针发现：

- 地图静止300次update产生15000次尺寸提交，其中13800次参数相同。
- 战斗静止300次update对意图文字、图片各重复提交300次；没有逐帧字号写入。
- 同一战斗覆盖页往返10次会重建10个敌人actor；该生命周期调整独立评估，本批先不改变。
- 普通update没有无条件重建整页，官方背景按缓存可见性切换。

本批仅对已证实的尺寸、意图文字及图片同值提交去重。成功写入后才缓存，按原生实例身份隔离；新对象、状态变化、重绑和失败恢复必须正常更新。先保留RED和原始计数，再验证修后300次静止调用与变化路径，保留既有输入、滚动、实例存活和所有权合同。

这些计数来自云端Fengari和原生API替身，不是手机FPS或加载耗时，也不能证明它们解释了玩家全部卡顿。冷载、持续帧耗时、切页与累积实例仍需同候选真实设备记录，证据不足保持未验收。
