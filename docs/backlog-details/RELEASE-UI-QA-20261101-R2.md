## 精确验收边界

**QA-R2-01｜卡牌裁切**
- 未选中的手牌允许遵从批准的扇形收纳视觉；但点选、悬浮、拖动抬升或详情查看时，当前牌的费用、牌名、类型、全部效果必须完整可读，边界不被屏幕底沿、遮罩或 HUD 错误截断。
- 核查长描述、连续多牌、选中中间/最左/最右牌、触屏与鼠标；不破坏出牌/取消/瞄准规则。旧的“底部内容有意只露一部分”与真实溢出分开报告。

**QA-R2-02｜药水图标**
- 当前顶部槽位里的瓶体不得出现未经批准的旋转、缩放过小、裁切或偏心；对照原始资源和批准视觉，用户能清楚识别药水且和已完成的种类区分要求兼容。
- 保留点击、选目标、使用/丢弃机制；如素材本身有设计倾斜，说明证据并仍需满足本轮 Owner 的视觉反馈，不把圆框端正视为瓶体已端正。

**QA-R2-03｜排序文字**
- 不用「排序·类型序」「名称序」「稀有度序」这类叠词。交互标签直接显示当前排序依据，如「类型」「名称」「稀有度」；仅显示**实际支持**的选项，若有方向用短箭头表达，不能暗中新增未实现的排序算法。
- 按钮文案无截断、无挤压。保持已有真实排序结果、筛选、稳定顺序与关闭返回逻辑；不再在弹层底部长驻长篇排序规则说明覆盖底层画面。必要解释仅在明确需要的入口查看，不替用户增加阅读负担。

**QA-R2-04｜居中与文字遮挡**
- 分别核查顶部战斗楼层文字、抽/弃牌弹层标题、筛选/排序/关闭操作区、底部说明的位置与文字适配；重要文本的锚点、内容、尺寸与 z-order 在实际横屏可用范围内正确，不能被按钮、牌面、底沿、遮罩盖住。
- 不靠无限缩小字号躲避溢出；优先简化文案、调整布局与安全区，并保留 TASK-4.20 已做的可读性改进。

**QA-R2-05｜抽/弃牌数量徽标**
- 单一数字徽标为小圆形，贴在对应牌堆图标的自然角位，而不是孤立放在标签下或屏幕边缘；两侧呈现规则一致，0/1/9/10+ 等数量完整显示，不悬空、不遮住牌堆和结束回合按钮。
- 仅换视觉呈现，不修改抽弃牌数据源、点按热区或结束回合规则；实体手机沿用 TASK-38.2 的误触保护验证。
