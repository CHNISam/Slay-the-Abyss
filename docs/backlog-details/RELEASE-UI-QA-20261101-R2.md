## 精确验收边界

**QA-R2-01｜卡牌裁切**
- 未选中的手牌允许遵从批准的扇形收纳视觉；但点选、悬浮、拖动抬升或详情查看时，当前牌的费用、牌名、类型、全部效果必须完整可读，边界不被屏幕底沿、遮罩或 HUD 错误截断。
- 核查长描述、连续多牌、选中中间/最左/最右牌、触屏与鼠标；不破坏出牌/取消/瞄准规则。旧的“底部内容有意只露一部分”与真实溢出分开报告。

**QA-R2-02｜药水图标**
- 当前顶部槽位里的瓶体不得出现未经批准的旋转、缩放过小、裁切或偏心；对照原始资源和批准视觉，用户能清楚识别药水且和已完成的种类区分要求兼容。
- 保留点击、选目标、使用/丢弃机制；如素材本身有设计倾斜，说明证据并仍需满足本轮 Owner 的视觉反馈，不把圆框端正视为瓶体已端正。

**QA-R2-03｜排序文字**
- 不用「排序·类型序」「名称序」「稀有度序」这类叠词。交互标签直接显示当前排序依据，如「类型」「名称」「稀有度」；仅显示**实际支持**的选项，若有方向用短箭头表达，不能暗中新增未实现的排序算法。
- 按钮文案无截断、无挤压。保持已有真实排序结果、筛选、稳定顺序与关闭返回逻辑；不再在弹层底部长驻长篇排序规则说明覆盖底层画面。必要解释仅在明确需要的入口查看，不替用户增加阅读负担。

**QA-R2-04｜居中与文字遮挡**
- 分别核查顶部战斗楼层文字、抽/弃牌弹层标题、筛选/排序/关闭操作区、底部说明的位置与文字适配；重要文本的锚点、内容、尺寸与 z-order 在实际横屏可用范围内正确，不能被按钮、牌面、底沿、遮罩盖住。
- 不靠无限缩小字号躲避溢出；优先简化文案、调整布局与安全区，并保留 TASK-4.20 已做的可读性改进。

**QA-R2-05｜抽/弃牌数量徽标**
- 单一数字徽标为小圆形，贴在对应牌堆图标的自然角位，而不是孤立放在标签下或屏幕边缘；两侧呈现规则一致，0/1/9/10+ 等数量完整显示，不悬空、不遮住牌堆和结束回合按钮。
- 仅换视觉呈现，不修改抽弃牌数据源、点按热区或结束回合规则；实体手机沿用 TASK-38.2 的误触保护验证。

**QA-R2-06｜地图页菜单里的无意义二次地图与退不出去**
- 重现路径：到当前幕**原本就显示的地图页** → 右上角菜单 →「查看地图」→ 仍显示同一幕相同地图 → 按返回仅回菜单 → 还需再按关闭才回正常地图。不是“没有地图功能”，而是**重复入口与嵌套返回造成误导**。
- 已核对最新 `develop@b0f64d49` 源：`src/lua/abyss_game_ui.lua` 的 `canViewRoute`（约 56–60 行）只要求 run/map 存在，未排除 `mode == 'map'`；`refreshForeground`（475–504）把 `runMenu.map` 开给当前 Run，并在 `routeOpen` 时把同一 `mapPanel` 提到最顶层；`run_map`（976–982）设 `routeOpen=true`；`closeExit`（152–169）仅清 `routeOpen` 就返回，仍留着 `exitOpen/menuOpen`。这是可核实的**重复预览状态链**，不同于前期 TASK-4.16 对未启程灰入口的修复。
- 固定《杀戮尖塔》初代对照（只读研究）：[TopPanel.updateMapButtonLogic 709–789](https://github.com/aeubanks/sts/blob/319009d5df0a82d9fb0f23cc22322286c6a87ec0/ui/panels/TopPanel.java#L709-L789) 处理导航/已在地图时的关闭切换；[DungeonMapScreen.open/close 265–318](https://github.com/aeubanks/sts/blob/319009d5df0a82d9fb0f23cc22322286c6a87ec0/screens/DungeonMapScreen.java#L265-L318) 将**临时浏览可关闭的地图**与正常地图区分；[SettingsScreen 35–50](https://github.com/aeubanks/sts/blob/319009d5df0a82d9fb0f23cc22322286c6a87ec0/screens/options/SettingsScreen.java#L35-L50) 保持独立菜单状态。不要想象原版靠复杂“多幕地图浏览”解决当前问题。
- **发版最低修复**：当玩家已经处于导航地图时，菜单中移除/隐藏重复「查看地图」；从战斗、商店等非地图场景临时查看地图时，返回/取消**一次恢复调用方原场景**，并把菜单状态、遮罩、焦点、输入代际清理完整；不能跳回额外菜单让玩家再关闭，也不能误使地图节点变为可选。
- 与原作已支持的交互语义对齐并适配千星输入 API；切勿借机开发跨第一/第二幕、回看所有幕的新 feature（当前不需要）。保留原有从非地图界面只读查看当幕地图的合法入口；不要粗暴删除全局 `routeOpen` 造成其它调用退化。
- 回归：地图→菜单→取消、战斗/节点→预览地图→一次返回、商店/营地/事件→预览→返回；鼠标/手机触摸/已支持的手柄退出/旧手势，重开与跨幕；关闭不穿透、地图节点不可误选、原房间状态/金币/库存/RNG 不变。**未取得同候选真实设备证据前不勾验收。**

**QA-R2-07｜商人对话采用成熟演出，不另起炉灶**
- Owner 反馈属于动态视觉/交互：文字在后方、似乎停住/不动、对话表演与角色不协调等现象，尚无本轮商店截图或视频，不能把主观描述当成已确定的 Z-order 或动画根因。
- 当前实现不是零基础：`src/lua/abyss_merchant.lua` 已有逐字文字（`shown` / `page` / `hold`）、分页/点击、买入/金币不足/离店/idle 反应与轻微点头/摇头；`src/lua/abyss_node_ui_shop.lua` 安装 merchant，`src/lua/abyss_node_ui_lifecycle.lua` 推进 `merchant:update(dt)` 并触发交易反馈。先检查实际 UI 容器 `merchantControl`、节点页 `shopView` 的显示顺序、锚点/遮挡/渲染、更新节奏和 `current` 换页时机；**不要重复造一个新的对话状态机**。
- 固定原版参考：[`shop/ShopScreen.java` 995–1034](https://github.com/aeubanks/sts/blob/319009d5df0a82d9fb0f23cc22322286c6a87ec0/shop/ShopScreen.java#L995-L1034) 将 `ShopSpeechBubble` 气泡和 `SpeechTextEffect` 文字同步生成/更新，停留与交易有条件触发；[`ShopSpeechBubble`](https://github.com/aeubanks/sts/blob/319009d5df0a82d9fb0f23cc22322286c6a87ec0/vfx/ShopSpeechBubble.java) 负责短时出入和气泡运动；[`SpeechTextEffect`](https://github.com/aeubanks/sts/blob/319009d5df0a82d9fb0f23cc22322286c6a87ec0/vfx/SpeechTextEffect.java) 负责逐词演出；[`Merchant` 94–118](https://github.com/aeubanks/sts/blob/319009d5df0a82d9fb0f23cc22322286c6a87ec0/shop/Merchant.java#L94-L118) 有自然闲置台词。原版的核心是商店交互不被无关对话强制阻塞、短暂台词/视觉与交易同步、交互层级清楚。
- **验收**：进店初次致意、停留、连买、缺金币、点商人/加速文字、离店告别，每次气泡、人物和可读文字在同一视觉层次，不卡字、不藏于商品/背景后、不出现离店后残留旧台词，字体和画布适配手机、PC；保持商店购买/取消/钱包账本原子性，不因为对话重建交易机制。
- 移植要求：**优先迁移原作已经验证的行为节奏、状态机和体验**，或采用许可清晰且真正兼容本平台的成熟开源实现；既有 Lua 组件能完成时不新增依赖或自己造一套体系。固定镜像为**反编译参考而非可无条件复制的开源授权**；遵守 `docs/SCOPE.md` 对未经授权源码、图片和音效的限制，不把任何未获许可的 Java 源码、气泡素材或台词直接复制入本项目。
- 先录制当前候选重现（或记录可解释的具体宿主状态）、对照源行为、最小修复及定向渲染/输入回归；真实设备演出通过才可勾对应 AC。未提供新实机证据时记为待修/待复验。
