## 1. 唯一研发主线

M9 工程架构与性能强化（先行，核心准入 3 天目标，必要时 3–7 天）
→ M7-A 美术与产品体验（优先做到可公开试玩）
→ M7-B 独立职业与原创玩法（达到美术＋玩法双核心）
→ M8 内容建设与扩充（更多职业和章节）。

- M7-A、M7-B 是 **M7 内部交付门槛**，不是两个新原生 Milestone；**M9、M7、M8 保留 #479/#480 的编号**，数字编号不代表实施先后。
- M9 不强制占满一个 7 天 Sprint；完成关键准入立即推进 M7-A。设计样稿、已知 Bug 修复可与 M9 并行，未通过工程准入不得大规模集成。
- M9 **工程准入**：已识别的重大耦合、运行时热点和 CI 阻塞获得修复或可审计的隔离处置；保留全部 Required Check 与独立复审。**完整验收**仍按 #480 的 SCC/复杂度、Full ≤30 分钟、Fast 至少 20 个自然 PR 的 P50 ≤5/P90 ≤10 分钟、跨平台/实机证据执行。不能用 3 天期限给未达标项勾 Done；无阻塞的统计采样可继续进行。
- 用户体验先于扩内容：M7-A 完成即可启动受控共创；M7-B 的自研职业必须实际可玩并通过真机验收，不能将岩旅 Ironclad 换名视为原创机制。M8 不阻塞三赛事当前交付。
- 同一候选的代码检查、官方导入/ready、PC、实体安卓和实际发布分开取证；不修改冻结卡表、许可或已有历史凭据，不自动发布。
