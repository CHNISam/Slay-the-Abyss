3. 核心语义行为/状态/事件/随机/回滚差分、原生输入/可见性/对象寿命、全部已启用工程门禁与 License 正常通过；独立深审明确 PASS/unresolved=[] 且与最终 PR head/base 一致。
4. 当前 PR 的**完整** Quality 与 inventory 真实通过、收据通过交付验证；合入后再证实际 develop commit、tree 和 push CI，不将 PR 合成提交冒充最终主线状态。
