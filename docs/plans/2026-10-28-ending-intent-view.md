# 第四幕意图信息实施计划

**目标：** 在既有战斗提示中完整显示盾矛与腐化之心的行动信息，保持纯预览和批准稿样式。

**设计：** 核心 Heart/Pair 提供与真实行动共享的纯计划；动作构造时捕获必须冻结的强化计划或伤害输出。新增 `abyss_battle_ending_intent` 只把计划转成现有渲染器支持的效果或描述，不抽随机数，不执行行动。旧显示流程只增加投影入口和两种描述。

**技术：** Lua、既有 BattleIntentView、Fengari 与严格原生控件测试。

1. 新增真实 Combat 的意图回归，先确认缺失格挡/强化/状态牌导致失败。
2. 抽取 Heart 的纯强化计划、Pair 的共享常量与纯意图补充；复用原行动逻辑并保存不可变快照。
3. 接入只读 UI 投影，沿用既有状态/格挡/群体说明和混合徽记。
4. 原 30 秒预算内核对所有阶段、负力量、空球位、Smash 的实际/意图舍入差异、动画快照、重复预览不变状态/RNG，并在构建生成的严格控件树点击查看。
5. 独立审查 diff 与必要邻接回归，提交给主集成人；不宣称实机、自然通关或整个 M3 完成。
