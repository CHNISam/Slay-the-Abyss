# 战斗流转与生命感升级实施计划

**Goal:** 岩系旅行者第一、第二幕的卡牌去向可见，角色持续待机，代表技能有差异，规则和输入契约保持不变。

**Architecture:** 复用已提交事件帧、UID、现有 poses、OnUpdate 和固定原生控件。卡牌根据真实牌堆差分选择目的地；待机以只读时间相位叠加，在动作、受击、死亡时让位；技能按真实身份与招式分类。核心与主题由中控统一集成。

**Tech Stack:** 千星奇域 Lua / 原生 UI、JSON 主题、Fengari 生产路径回归、现有 GIL 构建链。

## 方案与验收

采用现有反馈队列的小模块扩展。另建动画引擎会增加生命周期和输入风险；只加文字提示不能解决卡牌运动终点，均不采用。用户已明确授权自主选型、并行实施及合入。

1. 从 origin/develop d4c4b255 隔离五棵工作树；复核开放 PR 与 TASK-29/29.1/4/25.3。已有命中、音频、死亡过渡不重做。
2. A 先用真实命令写卡牌去向失败回归，再补弃牌、消耗、洗牌、能力和保留。不得改变 UID、事件顺序、结算和 RNG。
3. B 在纯表现模块提供旅行者、窃金客和守卫小样及中断优先级；动作合成仍由原 feedback 负责。
4. C 提供身份/招式分类与复用控件的差异化采样；原作美术不移植，不引入新资产依赖。
5. D 独立测规则/RNG、事件一次消费、多敌多段、连续出牌、大 dt、中断恢复、固定控件与清理。真实手机帧率不能由离线计时替代。
