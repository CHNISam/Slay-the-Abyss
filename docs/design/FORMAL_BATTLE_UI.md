伤害预演在完整隔离副本调用真实 `Combat.play`，读取相同敌人 ID 的结算后生命；原始状态（含事件、随机流）不写入。选择尚未完成、命令无效或核心调用失败时不显示扣血或击杀。普通牌面仍复用 `Combat.cardPreview`，不从牌面文字计算扣血。预演只在有效拖牌目标/投放区域出现，取消后恢复实际血条。

本轮采用可运行的原生圆片、菱形、线条和图库图标作为渐变、晶核和剑形替代。截图生成器使用原型字形替代图库，不能用这些图证明官方素材语义、原生字体或设备性能；同候选客户端和实体手机验收仍未进行，`verify:ui <候选.gil>` 仍是正式 UI 验收门禁。
