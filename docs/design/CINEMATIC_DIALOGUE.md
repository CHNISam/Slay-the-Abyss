# M4 开场演出、商人对话与标题清理

本文件说明本轮做了什么、怎么做的、验证到哪一层。规则、数值、随机流、地图和交易逻辑都没有改；交易仍由 `abyss_nodes` 执行，界面只在交易成功或被拒后做出反应。

## 1. 标题界面与开场演出

**标题界面**（`menuPanel`）：只在这里出现作品名「杀戮原塔2」，下面一行是篇章名「岩脉残响」（取自 Lore v2 的 `title`）。背后新增一层封印遗迹远景剪影 `vista`：偏右的残塔、塔顶封印环、碎片、左侧断柱与残墙、地平线微光、上浮的金色尘埃和四周暗角。全部是平台图片库的原生形状着色（见下表），不是 HTML 原型。胜利/失败结算复用同一远景，失败时封印变红。

**开场演出**（新控件 `prologuePanel`，控制器 `src/lua/abyss_prologue.lua`）：只在本次会话第一次从标题点「启程」时播放；结算后「重新启程」直接回地图，故事不重复。

| 节拍 | 文字（Lore v2 原文按句拆分，逐字未改） | 画面 | 音效 cue |
|---|---|---|---|
| 1 | 岩层深处传来了异常的共鸣。 | 黑场淡入，宽银幕黑边滑入；镜头对准残塔缓慢推近，开头有轻微震动 | `prologue_rumble` |
| 2 | 古老的封印正在崩解…… | 镜头推到塔顶封印；金光一闪，封印环红金闪烁，碎片向外崩落 | `prologue_crack` |
| 3 | 旅行者，深入遗迹，阻止深渊的侵蚀。 | 镜头拉远；旅行者的岩元素徽记带光晕从下方升起 | `prologue_rise` |

- 文字逐字出现（14 字/秒），左缘固定不跳动；左上角「序 · 岩脉残响」，底部三个进度点。
- **点击**：正在打字时先显示整句；整句显示后进入下一句；最后一句提示「点击进入遗迹」。每句开头 0.35 秒内的点击无效，避免一次连点同时跳过两句。
- **自动推进**：无人操作时前两句停 4.2 秒后自动接下一句，最后一句等待点击。
- **跳过**：右下角黑边内「跳过」，随时直接进入收尾。
- **衔接地图**：收尾先 0.45 秒淡入黑场，再把地图放到黑场下面，用 0.5 秒淡出黑场。淡出期间地图可见但不接受点击，卡组按钮隐藏；淡出完成后整个面板隐藏，地图才可操作。
- **退出/结算**：常驻「退出本局」在演出中仍可用；退出确认框打开时演出暂停、点击无效；确认退出进入结算时演出立即取消，不残留遮罩。
- **计时**：本局用时不计入演出时间。
- **触摸**：支持按下/抬起事件的设备，必须在演出内按下再点击才算数；从标题带过来的点击、中途滑出的触摸都会被忽略。

背景接入说明：TASK-4.2 负责的三维官方遗迹景片尚未导入或实机验证。本层二维剪影是界面里的远景层，用低对比冷灰蓝，不与三维方案冲突；三维远景实机可见后，可在宿主隐藏 `menuPanel/vista`，其他控件不动。

## 2. 商店商人与对话框

新控件 `nodePanel/merchant`，控制器 `src/lua/abyss_merchant.lua`，接入 `abyss_node_ui.lua`。

- **形象**：「旧路商人」（Lore v2 暂定称呼）的半身剪影——兜帽、长须、长袍、灯笼暖光、两点微亮的眼睛，放在金边圆形徽章里。平台图片库里没有合适的老人肖像（`creature` 分类只有怪物与动物），所以用原生圆形/菱形着色拼成；灯笼光会轻微闪烁。
- **对话框**：底部居中，夹在「返回」「离开商店」两个按钮之间，位于遗物价格下方，不压货架、价格和按钮。名牌「旧路商人」，对白逐字出现（40 字/秒），说话加「」，旁白用暗色且不显示名牌；有下一句时右下角小菱形上下浮动。点对话框：先显示整句，再到下一句。
- **台词**（全部为 Lore v2 已批准文案）：

| 时机 | 内容 | 反馈 |
|---|---|---|
| 本局第一次进商店 | 旁白「转过一道石廊……」→「路不好走吧？来，看看有没有用得上的。」 | 旁白读完 2.6 秒后自动接欢迎语 |
| 之后的商店 | 「路不好走吧？……」 | — |
| 买卡、买遗物、删牌成功 | 「眼光不错。」 | 商人点头；`merchant_buy` |
| 金币不足仍点商品或删牌 | 「这可不够啊，小姑娘。」 | 商人摇头抖动；`merchant_deny` |
| 停留 14 秒无新对白 | 「做生意嘛，总得知道哪条路安全。」 | 每次进店最多一次，不是新按钮 |
| 离开商店 | 「前面可不像这里太平。一路小心。」 | 停在商店画面，按「继续」回地图 |

- **不拖慢反复购买**：新反应立刻打断当前句子，货架按钮始终可点。
- 顶部提示栏只留事实：「点选商品直接购买……」「已购买「X」· 支付 N 金币」「金币不足：需要 N，还差 M」；商人台词不再混在提示栏里。
- 删牌选择界面会盖住对话框的位置，所以选牌时商人暂时隐去，返回后再出现。
- 离开商店改为像营地/事件结果一样停在当前画面，多一次「继续」，让告别语真的被看到；只有离开时多这一步，购买不受影响。

已知平台风险（需要实机确认）：

1. 静态 `opacity` 与运行时 `imageColor` alpha 是否相乘——光晕、封印环、对话框底板用了静态透明度。
2. `align: left` / `valign: top` 文本：导入器支持，但本项目之前只验证过居中。
3. 镜头推近时 `vista` 放大到 1.35 倍，是否有锯齿或性能问题。
4. 约 2000 个控件（新增约 70 个），手机端帧率。
5. 字宽估算按每个中文字一个字号宽，实际字体可能略有偏差。
