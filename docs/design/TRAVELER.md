# 旅行者卡牌表现：荧·岩元素

## 本轮目标

主角为《原神》的荧（Lumine），本次参赛只做岩元素形态，保留单手剑战斗。风元素候选已撤回；其他元素不在本轮范围。

只调整玩家显示名与角色说明，不改现有 37 张卡的 ID、费用、数值和效果。基础牌叫“普通攻击”“防御”，两次剑击叫“重击”；不是把所有攻击改成岩元素附魔。

## 少量官方锚点，其余说清动作

| 当前卡 ID | 玩家名称 | 参照与本作差异 |
|---|---|---|
| strike / twin_strike | 普通攻击 / 重击 | 参照单手剑普通攻击和两剑重击；本作仍按卡牌结算，不实现原作五段连招、体力或动作时序。 |
| cleave | 星陨剑 | 采用官方战技名与范围攻击意象；本作只造成群体伤害，不生成荒星，不实现攀爬或阻挡。 |
| whirlwind | 岩潮叠嶂 | 采用官方爆发名与多段范围冲击意象；本作耗尽剩余能量决定次数，不生成岩嶂，不附带击退。 |
| barricade | 永世的磐岩 | 借用六命名称及防御延续意象；本作保留格挡，不是官方的创造物持续时间延长。 |

其余使用朴素动作、攻防与战术表达，例如“招架还击”“试探一击”“乘隙追击”“集中精神”。所有 37 张显示名只维护在表现资源中，不在本文重复一份卡表。

- “格挡反击”是主动打出后按当前格挡造成伤害，不是受击自动反伤。
- “透支”“舍身进攻”“奋力一搏”仍实际扣除生命；“以战养战”仍按实际造成伤害回血。这四张是本作卡组改编，不是荧的官方技能。
- 格挡、力量、抽牌、易伤与虚弱均为本作卡牌规则。名称不代表已接入原神护盾、暴击、元素伤害或元素反应。

## 官方资料核对与取舍

- 普通攻击：官方名称“异邦岩峰”，含五段剑击、两剑重击和下落攻击。按 Owner 反馈，玩家牌名不用“异邦”。
- 战技 / 爆发：星陨剑 / 岩潮叠嶂，作为本轮两个主要识别锚点。
- 两项基础被动：破碎的绝岩（战技冷却缩短）、狂乱的崩岩（普攻末段追加范围岩伤）。当前没有对应触发器，不硬套名字。
- 六命：巍然的青岩、不稳的熔岩、八方之岩、险峻的重岩、天坠之岩、永世的磐岩。除上表的持续意象改编外，不把暴击、造物销毁爆炸、天赋等级或命中回能说成已实现。
- 新版额外天赋：官方已确认 Luna IV 的剧情解锁；“异邦的坚岩 / 古岩之刃 / 岩坠”等岩系细则本次由中文社区资料交叉核对。当前未实现其造物、护盾与叠层条件，也不追加衣装前置，本轮不采用。
