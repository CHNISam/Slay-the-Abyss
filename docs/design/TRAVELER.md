# TASK-7.3 · 荧（风元素）卡牌表现

## 角色与范围

本次参赛主角为《原神》的**荧（Lumine），只做风元素**。卡组围绕单手剑、掌中风涡、风刃与龙卷展开，替换原先泛指旅行者的行囊、营地主题；其他元素和角色不在本次范围。

这是**风元素荧的卡牌化改编**，不是原神技能的逐项复刻。保留现有37张卡的ID、数值、费用、效果及升级规则，只重做表现名称。源表保留机制溯源，玩家文案使用 `data/presentation/traveler.zh-CN.json`，不直接显示源表名称。

## 三个辨识点

- **疾风斩**：本作基础剑术名称，对应单体攻击，不称风元素伤害。
- **风涡剑**：掌中风涡意象，对应一次全体伤害；“风涡迸发”为本作强力单体变体。
- **风息激荡**：龙卷意象，对应X费多段全体伤害，不沿用原神的持续时间、能量与位移规则。

“风涡剑”和“风息激荡”沿用角色招式名；“疾风斩”及其余名称为本作原创改编。牌组分为剑术连击、风势攻防、凝神调息与极限发力；例如“余风追斩”复制本牌，“借风回身”格挡并抽牌，“长风蓄势”逐回合获得力量。完整映射只维护在JSON中。

## 后续动效接入参照（未实现）

- 风涡剑：掌心聚风、风涡凝聚后向外爆开；对应本作全体攻击，不把画面的吸引感误报为已实现牵引。
- 风息激荡：向前送出龙卷，以连续命中表现多段伤害；不自行增加元素转化或扩散结算。

## 机制边界

- 当前没有元素附着、扩散、元素转化、牵引或风抗结算；易伤不能称降低风抗。格挡是本作防御规则，不是原神护盾，消耗手牌也不是消耗元素。
- “逆风透支”“逆风强攻”“极限聚风”保留原卡扣血换收益，表现为本作极限发力代价，不是荧的官方能力或血魔法。
- “回风复苏”按本次实际伤害回血，是本作改编，不冒充原版天赋触发条件。
- 规则模板保留对象、条件、顺序、次数、随机/选择、时点与消耗。数字只读源占位符；升级为顶层浅覆盖，X费不显示为免费。上游op、条件或标记变化须人工复核，渲染成功不代表语义正确。
