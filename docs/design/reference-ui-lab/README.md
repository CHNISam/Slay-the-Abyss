# 浏览器界面参考原型

2026-11-05 私人参考站源码更新的公开安全副本，源版本 `7e40d2d361fff6b9c89d9f409db29a9d8ac44352`。独立于正式游戏，不是原生游戏实现或像素级视觉验收。

## 本地运行

```sh
python3 -m http.server 8080 --directory docs/design/reference-ui-lab
```

打开 `http://localhost:8080/`；卡牌对比用 `http://localhost:8080/cards.html`。无需安装依赖。ES modules 不支持直接 file:// 打开。

## 本批内容

- 九个中文页面与独立卡牌展示；移除设置页和主菜单设置入口，保留局内菜单与退出确认，不提供保存/继续入口。
- 选角必要控件、起始角色/文案、地图节点交互按参考调整。
- 15张项目真实卡牌名称/数据，多类型及稀有度展示；角色卡底深灰褐和浅金。
- 卡牌插画占位补满对应内框；能力底色统一采自原版 Inflame 的深蓝紫背景，并非声称原版存在统一能力色。插画仍是占位图标。
- 中文标题/正文使用可合法嵌入的 Noto Sans Mono CJK SC 字体子集；类型用 Noto Serif CJK SC Bold 近似。许可证随文件保存。
- 本局地图、战斗和祝福只保存在当前页面内存；刷新/离开即丢失。localStorage 只保留已有快速模式偏好，不保存游戏进度。
- 胜利/失败结算、重新启程、退出本局与平台结算演示已同步；独立样例与真实原型本局统计明确分开。彩蛋画面不公开，仅保留手动入口、来源说明与返回。

## 公开版与私人站差异

公开副本**不含**原版卡底、稀有度框/横幅、费用球或平台预览图标，以及把这些图片嵌入的SVG。相应部位继续使用独立简易几何SVG，因此公开版不能用来验收私人站的原版纹理效果。项目/用户此前批准公开的图片保持原样。无新增第三方原画或截图。详见 [ASSET-PROVENANCE.md](ASSET-PROVENANCE.md)、[FONT-LICENSES.txt](FONT-LICENSES.txt)。
