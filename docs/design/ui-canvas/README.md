## 意图图标要点
- 无边框，图标本身带同色发光；数字为粗斜体白字加深色描边。
- 攻击只用一把剑，数字写最终伤害；多段写「单段×段数」，不另出图标。
- 图标沿用游戏现有素材，设计只定排布：多个意图从左到右并排（攻击在前）、不叠放；数字小号白字压在攻击图标左下。
- 沉睡、眩晕、未知等无威胁意图用暗铜色、不发光。

## 总原则：能用原神 / 官方素材就不自造
凡是图库里已有可替代的图标、图片（意图、状态、地图节点、顶栏、牌堆、更新公告分类等），一律用现成素材，只按设计稿调整位置、尺寸、颜色和层级；自绘只在确实没有素材时才做。卡牌（卡框、费用环、类型窗形状、卡背）、瞄准星点连线、伤害预演这类官方素材做不出效果的，按设计稿自己做。理由：现成素材不增加图片控件和资源开销，风格也与平台一致。

## 交接：意图与牌堆按现有素材实现（不用设计稿里的自绘图标）

设计稿里的意图图标、牌堆卡背只是占位示意，**实现时继续用游戏里现有的千星奇域图库素材**，只按下面的排布和规则调整。

### 敌人意图
- 素材：沿用当前在用的意图图标（攻击、防御、强化、削弱、未知等），缺的从官方图库挑同风格的补，不新画。
- 位置：敌人头顶正上方，跟随立绘高度（立绘高的敌人意图跟着上移）。
- 多个意图：**从左到右并排，不叠放**，间距约半个图标宽；顺序 攻击 → 防御 → 强化 → 削弱 → 其它；最多 3 个，再多只在悬停详情里列出。
- 数字：只有攻击带数字，小号白字（约图标高度的 45%）、黑色细描边或投影，压在攻击图标**左下角**；多段写「6×2」。数字是算完力量、虚弱、易伤之后的最终值。
- 攻击不按伤害高低换图标，单段多段都用同一个攻击图标。
- 颜色不另外加光晕、底框；图标本身颜色即可。
- 悬停意图：弹出说明，攻击显示算式（基础 9 ＋ 力量 3 ＝ 12）。
- 需要后端：每个敌人输出意图列表（类型、最终数值、段数）给视图；视图按上面规则排布。

### 抽牌堆 / 弃牌堆
- 素材：沿用游戏里现在的抽牌堆（＋）/ 弃牌堆（－）图标，或换成官方图库里更贴切的牌堆图标；不用设计稿里的卡背。
- 位置：抽牌堆左下角，弃牌堆右下角，与现在一致。
- 数量：深色圆底 + 金色细边的数字角标，抽牌堆角标在右上，弃牌堆在左上（与现截图一致）。
- 点击打开对应牌堆列表。

### 状态图标
- 素材：**直接用游戏现有 / 官方图库的状态图标**，设计稿「图标与状态规范」里自绘的 19 个图标只用来说明语义和配色，不出图、不替换现有素材。
- 只按规范调整：血条下方一行，每行最多 5 个、最多 2 行，第 10 个起显示「+N」；层数角标深色圆底；增益/减益靠图标底框边色区分（金 / 紫）；超过 99 写 99+，力量、敏捷为负写 −N。
- 若某状态在图库中确实没有对应图标，再从官方图库挑语义最接近的，仍不自绘。

### 地图节点图标
- 素材：战斗、精英、事件（未知）、商店、宝箱、首领**沿用现在的官方图标**，不改。
- 唯一要换的是**营地**：现图标与其它节点风格不搭，从官方图库另选一个篝火 / 帐篷类图标替换（同样的单色剪影、同尺寸）；设计稿里的篝火只是示意。
- 节点状态按地图稿：可前往 = 亮底 + 金色光圈，已走过 = 暗金细环，未到达 = 只显示图标，当前位置 = 主角菱形令牌；不再需要「节点状态」图例。

### 顶栏与能量图标
- 生命（心形）、金币、遗物、药水瓶、牌组、菜单、能量球内的元素图标：**都用官方图库现有图标**，设计稿里的自绘图形只是示意。
- 只按稿子调整位置和层级：左侧 生命 → 金币 → 药水槽，右侧 牌组 → 菜单；能量球在手牌左侧，数字「当前/上限」居中、白字带投影。

### 瞄准连线（拖牌 / 药水共用）
不改成箭头，**保留现在的星点连线，做精修**（见拖牌稿 ⑫ 与药水瞄准稿 ③）：
- 曲线：二次贝塞尔，起点 = 牌顶中心（药水为药水槽中心），终点 = 指针位置；控制点取两端中点，高度 = 两端较高者再往上 160，且不高于屏幕顶 150 的位置。
- 星点：沿曲线均匀取 14 个点，用同一个官方星形图标做精灵；尺寸从起点 10 线性增大到终点 28，越靠近目标越大。
- 颜色：前 60% 金色，后 40% 红色；指针**没有落在有效目标上时全部保持金色**，落到有效目标上后尾段变红。每个星点加 4px 同色柔光。
- 目标：有效目标出现四角红色准星（不要盖住头像的大圆圈），血条预演扣血，够击杀写「击杀」。
- 实现（原生 UI）：预分配 14 个图片控件放在一个容器里，拖动时每帧按上面公式重算位置、尺寸、颜色；松手或取消时整组隐藏。不需要额外素材。
