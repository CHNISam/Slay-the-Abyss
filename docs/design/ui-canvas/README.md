## 意图图标要点
- 无边框，图标本身带同色发光；数字为粗斜体白字加深色描边。
- 攻击只用一把剑，数字写最终伤害；多段写「单段×段数」，不另出图标。
- 图标沿用游戏现有素材，设计只定排布：多个意图从左到右并排（攻击在前）、不叠放；数字小号白字压在攻击图标左下。
- 沉睡、眩晕、未知等无威胁意图用暗铜色、不发光。

## 交接：意图与牌堆按现有素材实现（不用设计稿里的自绘图标）

设计稿里的意图图标、牌堆卡背只是占位示意，**实现时继续用游戏里现有的千星奇域图库素材**，只按下面的排布和规则调整。

### 敌人意图
- 素材：沿用当前在用的意图图标（攻击、防御、强化、削弱、未知等），缺的从官方图库挑同风格的补，不新画。
- 位置：敌人头顶正上方，跟随立绘高度（立绘高的敌人意图跟着上移）。
- 多个意图：**从左到右并排，不叠放**，间距约半个图标宽；顺序 攻击 → 防御 → 强化 → 削弱 → 其它；最多 3 个，再多只在悬停详情里列出。
- 数字：只有攻击带数字，小号白字（约图标高度的 45%）、黑色细描边或投影，压在攻击图标**左下角**；多段写「6×2」。数字是算完力量、虚弱、易伤之后的最终值。
- 攻击不按伤害高低换图标，单段多段都用同一个攻击图标。
- 颜色不另外加光晕、底框；图标本身颜色即可。
- 悬停意图：弹出说明，攻击显示算式（基础 9 ＋ 力量 3 ＝ 12）。
- 需要后端：每个敌人输出意图列表（类型、最终数值、段数）给视图；视图按上面规则排布。

### 抽牌堆 / 弃牌堆
- 素材：沿用游戏里现在的抽牌堆（＋）/ 弃牌堆（－）图标，或换成官方图库里更贴切的牌堆图标；不用设计稿里的卡背。
- 位置：抽牌堆左下角，弃牌堆右下角，与现在一致。
- 数量：深色圆底 + 金色细边的数字角标，抽牌堆角标在右上，弃牌堆在左上（与现截图一致）。
- 点击打开对应牌堆列表。
