## 意图图标要点
- 无边框，图标本身带同色发光；数字为粗斜体白字加深色描边。
- 攻击按最终伤害分三档：<10 短刃、10–19 长剑、≥20 巨剑加火星。多段为交叉双刃，写「单段×段数」。
- 混合意图：主图标 + 右下角标（紫色水滴 = 附带减益，蓝色盾 = 同时获得格挡）。
- 沉睡、眩晕、未知等无威胁意图用暗铜色、不发光。
