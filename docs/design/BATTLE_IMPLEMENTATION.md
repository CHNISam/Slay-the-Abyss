# TASK-10 战斗界面对齐记录

本切片遵循已批准的 [界面规范](UI_DESIGN.md)、`data/presentation/ui_theme.json` 与 `screens/battle.png`、`drag.png`、`boss.png`。保留既有真实 Run/Combat 战斗、奖励入牌组和再次挑战流程；只读核心状态并发送现有命令，不修改规则、地图、数值、主题源表或其它节点界面。

## 已落实

| 组件 | 当前实现 |
|---|---|
| 主题 | 构建树直接读取共享 JSON；Lua `require("abyss_theme")`。`build:ui` 同时生成该主题，颜色统一转换为 0–255。没有另建色板。 |
| 画布 | 1280×720 stage、父容器中心偏移、y 向上。启动及画布尺寸变化时取 `min(w/1280,h/720)` 缩放。底色在 stage 外，按实际画布设置尺寸，覆盖宽屏两侧。 |
| 安全区 | 点击目标按左右 40、上下 20 约束。1–10 张牌的常态、旋转、选中包围盒均有独立测试。手机、1600×900、1920×1080、1560×720 已自动计算验证，平台预览仍待做。 |
| 卡牌 | 148×208，名称、类型插图、类型条、说明、费用圆；稀有度边框、攻击/技能/能力色、升级绿名及加号、X 费用。字号取主题且最小 14。 |
| 手势 C 档 | 第一次点击选牌并抬起 36、放大 1.22、金色高亮，置于其它牌前；需要目标时点活敌人执行，无目标时再次点同牌执行；换牌只改变选择。可选敌人亮金框，提示点选目标。 |
| 不可出牌 | `Combat.canPlay` 是唯一合法性判断；费用红字、暗费用圆、暗插图区、灰框及灰字。点击给出核心失败原因，不扣能量、不移牌。 |
| 单位 | 旅行者头像 132、普通敌人最高 120、首领 168，图库图片取主题。遮罩血条按实际生命填充；有格挡时蓝边及盾牌数字；核心状态层数以文字显示。 |
| 能量与牌堆 | 能量球 88、岩元素底纹、当前能量/每回合基础能量；零能量暗色。抽牌、弃牌、消耗、金币和牌组数量即时刷新。 |
| 意图 | 主题图标和语义色，攻击次数以 `值×次数` 表示。点击未选牌的敌人显示意图说明。当前伤害明确写“基础”，原因见下表。 |
| 按钮 | 使用原生 presetButton，normal/hover/pressed/disabled 四个子控件均齐全，按下缩至 0.96。核心非我方阶段及命令执行锁期间禁用；无可用牌时结束回合变琥珀主按钮。 |
| 胜败 | 胜利文字反馈后可选择奖励或跳过；奖励真实进入牌组。失败显示危险色反馈并可重新启程。仍是既有战斗演练入口，不声称实现整局或正式结算。 |

## 有意降级与未实现项

| 项目 | 差异 / 原因 |
|---|---|
| 意图最终伤害 | **核心接口缺口**：`Combat.intent` 只复制基础 effects，未提供力量、虚弱、易伤修正后的只读预览。界面不复制计算公式，暂标“基础”；不能把这些值当作实际结算伤害。最终预览须由核心独立提供后接入。 |
| 跟手拖动 A / 假拖动 B / 甩牌 | **未实现、未平台验证**。未取得拖动指针与移动端按住进入事件的证据，保持 C 档可测试。 |
| 安全区下缘 | 主题手牌中心 y=−250 会让完整卡牌下缘越过 20 安全区。运行时按旋转后包围盒将整张牌向上约束；保留主题源表。费用圆内移至卡面左上，名称避开圆圈。 |
| 四至五敌人 | 保持字体大小，压缩头像及血条宽度；窄单位的盾牌移至血条左端内侧，避免遮住相邻敌人。首领单体仍使用 168 头像。 |
| 不可出牌的整体去饱和 | 原生图像用共享暗色 token 分区压暗；没有宣称实现 CSS 全卡饱和度滤镜。 |
| 状态与数字 | 状态目前用核心名称和层数文本；未做每个状态的 26 图标网格。说明数字未逐字富文本着金。图库 `verify` 组仍未实机核对。 |
| 悬停 / 长按提示 | 未接入 350ms 长按和悬停浮层；点选后完整卡牌置顶可阅读，敌人点击可查看意图。 |
| 动效 / 音效 | 抬起、缩放、血条、死亡及胜败为即时状态变化；未接事件队列逐条动画、血条残影、伤害数字、Tween 飞牌、抖屏、横幅时序、音效或减少动效开关。核心回合命令同步执行，界面在命令前设输入锁，执行后解锁。 |
| 顶栏和其它界面 | 未新增药水命令、药水槽操作、遗物交互、卡组/地图入口或正式结算。保留已有演练奖励和再次挑战，不替代其它节点任务。 |
