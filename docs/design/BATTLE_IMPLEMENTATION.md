# TASK-10 战斗界面对齐记录

本切片遵循已批准的 [界面规范](UI_DESIGN.md)、`data/presentation/ui_theme.json` 与 `screens/battle.png`、`drag.png`、`boss.png`。PR #29 冲突整合保留本切片的视觉与 C 档选择交互，同时接回完整地图/七节点宿主和库存规则；完整入口及交付边界见 [CLIENT_UI.md](../CLIENT_UI.md)。独立演练模式保留用于单独验证，游戏入口使用嵌入式控制器。

## 已落实

| 组件 | 当前实现 |
|---|---|
| 主题 | 构建树直接读取共享 JSON；Lua `require("abyss_theme")`。`build:ui` 同时生成该主题，颜色统一转换为 0–255。没有另建色板。 |
| 画布 | 1280×720 stage、父容器中心偏移、y 向上。启动及画布尺寸变化时取 `min(w/1280,h/720)` 缩放。底色在 stage 外，按实际画布设置尺寸，覆盖宽屏两侧。 |
| 安全区 | 点击目标按左右 40、上下 20 约束。1–10 张牌的常态、旋转、选中包围盒均有独立测试。手机、1600×900、1920×1080、1560×720 已自动计算验证，平台预览仍待做。 |
| 卡牌 | 148×208，名称、类型插图、类型条、说明、费用圆；稀有度边框、攻击/技能/能力色、升级绿名及加号、X 费用。字号取主题且最小 14。 |
| 手势 C 档 | 第一次点击选牌并抬起 36、放大 1.22、金色高亮，置于其它牌前；需要目标时点活敌人执行，无目标时点击明确战场出牌区域执行；再次点原牌取消，换牌只改变选择。可选敌人亮金框，提示点选目标。 |
| 不可出牌 | `Combat.canPlay` 是唯一合法性判断；费用红字、暗费用圆、暗插图区、灰框及灰字。点击给出核心失败原因，不扣能量、不移牌。 |
| 单位 | 旅行者头像 132、普通敌人最高 120、首领 168，图库图片取主题。遮罩血条按实际生命填充；有格挡时蓝边及盾牌数字；核心状态层数以文字显示。 |
| 能量与牌堆 | 能量球 88、岩元素底纹、当前能量/每回合基础能量；零能量暗色。抽牌、弃牌、消耗、金币和牌组数量即时刷新。 |
| 意图 | 主题图标和语义色，攻击次数以 `值×次数` 表示。点击未选牌的敌人显示说明；数值调用核心 `attackAmount/blockAmount`，标明“当前修正”。 |
| 按钮 | 使用原生 presetButton，normal/hover/pressed/disabled 四个子控件均齐全，按下缩至 0.96。核心非我方阶段及命令执行锁期间禁用；无可用牌时结束回合变琥珀主按钮。 |
| 胜败 | 胜利后选择奖励或跳过，奖励真实进入牌组；宿主在节点完成后返回地图。失败和 Boss 胜利可重开新局；本地结果页仍不等于平台正式结算。 |

## 有意降级与未实现项

| 项目 | 差异 / 原因 |
|---|---|
| 意图最终伤害 | 已接核心的当前状态修正算术，不复制公式。由于回合末状态衰减，当前修正不代表未来最终生命损失；格挡与后续状态变化仍以核心执行为准。 |
| 跟手拖动 A / 假拖动 B | TASK-30 已接 A 档离线控件回归，无目标牌在战场区域松手出、目标牌只命中合法敌人，C 档保留。原生捕获与手机实机仍待验；当前规范见 [CARD_DRAG_PLATFORM.md](CARD_DRAG_PLATFORM.md)，不支持甩牌自动选敌。 |
| 安全区下缘 | 主题手牌中心 y=−250 会让完整卡牌下缘越过 20 安全区。运行时按旋转后包围盒将整张牌向上约束；保留主题源表。费用圆内移至卡面左上，名称避开圆圈。 |
| 四至五敌人 | 保持字体大小，压缩头像及血条宽度；窄单位的盾牌移至血条左端内侧，避免遮住相邻敌人。首领单体仍使用 168 头像。 |
| 不可出牌的整体去饱和 | 原生图像用共享暗色 token 分区压暗；没有宣称实现 CSS 全卡饱和度滤镜。 |
| 状态与数字 | TASK-10.5：单位血条下为 26 图标网格（每行最多 5、两行，窄列按宽度减列，溢出末格显示 `+N`），层数在右下角，增益橙、减益紫（负力量/敏捷按减益）。力量与仪式/激怒、虚弱与缠绕等共用主题图标 ID，单靠图标无法区分，以详情面板文字为准；图库 `verify` 组仍未实机核对。说明数字未逐字富文本着金：平台文本富文本能力未取证，整段统一原生文本色。 |
| 手牌动态数值 | TASK-10.5：伤害、群攻、格挡数字由核心只读 `Combat.cardPreview`（复用 `attackAmount/blockAmount`）在每次渲染时计算，含力量、虚弱、易伤、敏捷、脆弱与暴走成长。未定目标显示存活敌人区间（如 `9~13`），拖牌瞄准时显示该目标精确值，群攻始终为各存活敌人区间；格挡反击追加“（当前 N 点）”。按出牌前状态计算，不预演同一张牌内先后效果的相互影响。奖励、商店与牌组视图仍显示印刷数值。 |
| 悬停 / 长按提示 | 未接入 350ms 长按和悬停浮层（平台指针进入/长按未取证）。降级为点按：玩家头像或任一单位的状态行打开 360 宽深底金边详情面板（名称、生命/格挡、每项状态的层数、增减益与当前效果，最多 6 行，超出注明条数）；面板打开时下一次按下或点击只关闭面板，不出牌、不改目标、不结束回合、不开始拖牌。敌人头像保持选目标与意图提示，不弹面板，以免药水选目标后的下一次点按被吞掉。 |
| 动效 / 音效 | 抬起、缩放、血条、死亡及胜败为即时状态变化；未接事件队列逐条动画、血条残影、伤害数字、Tween 飞牌、抖屏、横幅时序、音效或减少动效开关。核心回合命令同步执行，界面在命令前设输入锁，执行后解锁。 |
| 顶栏和其它界面 | PR #29 已补三药水槽、同源效果及完整地图/节点入口。卡组/遗物详情、批准的节点完整视觉及平台正式结算仍未完成。 |

## 本轮验证

- `npm run build:ui`：成功生成原生控件树、旅行者显示表、共享 Lua 主题。
- `npm run check`：通过。JavaScript 86 项中 80 通过、6 项因 Windows 无符号链接权限明确跳过；Lua 68 项通过（战斗界面 9、战斗核心 15、地图 10、Run 8、状态 26）；Python 11 项中 10 通过、1 项同样因符号链接权限跳过。
