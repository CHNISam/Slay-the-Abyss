# 原生客户端界面与节点流程

入口 `src/lua/abyss_ui.lua` 的 `OnStart()` 创建统一宿主，组合菜单、地图、战斗和节点面板。界面只读状态并调用 `Run` / `Nodes`，数值来自已有 JSON。

本地运行：

```powershell
npm ci --ignore-scripts
npm run check
```

`npm run build:data` 生成同源 `build/lua/abyss_data.lua`；`npm run build:ui` 用现有 Python 表现渲染器生成 `abyss_presentation.lua`、统一主题 `abyss_theme.lua`、原生控件树 `game-ui.json` 和测试用 `abyss_ui_layout.lua`。需要 Node 22+、Python 3（仅标准库）；可用 `ABYSS_PYTHON` 指定解释器。生成物不入库。

平台接线应导入 `game-ui.json` 的控件，根脚本为 `abyss_ui`；保留 `src/lua/*.lua` 的模块名，以及同源生成的 `abyss_data`、`abyss_presentation`、`abyss_theme`、`abyss_map_layout`。`abyss_ui_layout` 和 `abyss_map_controls` 仅供测试，不是游戏规则。`build:ui` 同时生成独立战斗/地图控件及完整宿主。根控件包含全画布底色与 stage，入口按 `game.GetUICanvasSize()` 设置统一缩放，`OnUpdate` 响应画布变化并更新地图呼吸。嵌入式战斗/地图控制器不再次缩放；独立模式继续保留。平台导入仍遵守 `TOOLCHAIN.md`：先读 MCP workflow/platform-rules，只写存档副本，保留 live write 为 0。

## 当前流程

- 菜单开始后生成同局地图；地图使用批准稿的滚动视窗、圆节点、七类图标、四态与真实连线展示 15 层，显示时定位当前层。处理当前节点及战斗奖励期间导航锁定。
- 战斗保留批准稿的 148×208 卡面、扇形手牌、选牌抬起、头像/填充血条和四态按钮；先点选牌，需要目标时再点敌人，无需目标时再点同牌确认。真实初始卡组、能量、血量、格挡、牌堆、双方状态和意图随操作刷新。意图标注“当前修正”，所有者回合末状态衰减可能改变随后数值；奖励阶段显示遗物回血后的局内生命。非目标牌选中后点敌人只查看意图，保留主线回归修复。
- 七件表内遗物分别在开战或胜利后触发；七种药水可通过三个固定场内按钮使用。火焰伤害和护盾数值不受卡牌修正，非法目标/溢出等拒绝不消费药水；药水击杀末敌走正常奖励。消耗后保留空按钮位，连续点击不会误喝下一瓶。
- 营地可休息或升级；商店可买当前已支持的卡、买遗物、按独立 UID 删牌；金币不足拒绝且不改变资源，删除费用跨商店递增。
- 宝箱产出未拥有遗物，池耗尽时用现有普通战斗金币字段；首发最小事件可选现有普通金币或表内药水，不声称复刻原版事件。
- 战斗奖励消费后才完成节点。抵达 Boss 与击败 Boss 分开：后者显示结果并允许新局；死亡重开会替换原局资源、地图与控制器状态。

## 验证边界与后续

`tests/lua/game_ui.lua` 从生成的真实控件树构建测试宿主，点击实际处理器并调用真实 Run/Map/Nodes。包含原数据初始牌组战斗及奖励入组、隐藏面板输入拒绝、失败重开，以及全部七节点连续十五层流程。十五层用例仅降低测试数据敌人 HP，以隔离流程与平衡；不代表原数值通关。

独立测试还覆盖状态时序、非法交易原子性、重复领取、稳定升级/删牌 UID、分页与画布边界。控件测试使用原生 API 的测试替身，几何检查仅证明声明的控件范围；不等于平台实际文字排版、手机/主机预览或游戏试玩。

## 与已批准美术稿的差异

PR #19 仍是最终视觉依据。冲突整合采用 `develop` 已合入的战斗与滚动地图，接入七节点和库存规则。节点和菜单仍使用主题的 `layout.nativeNode/nativeMenu` 过渡布局；旧 `nativeBattle/nativeMap` 参数保留用于历史记录，完整宿主不再使用旧分页地图或矩形文字手牌。stage 缩放读取生成的 Lua 主题。

尚未完成：奖励专用弹窗、营地升级前后卡面对比、商店批准货架、状态图标网格、完整动画/音效和 A/B 档拖牌。商店与节点当前仍是分页清单。这些是实现缺口，尚无平台能力证据支持称为必要降级；需要在 TASK-10 / TASK-24 继续还原。图库观感、实际触摸及手机/主机排版继续等待平台验收，不因本地布局存在就关闭美术任务。

当前商店/奖励会过滤尚不支持的高级卡，当前可售卡池为 17 张；37 张内容表不等于 37 张可玩，30+ 完整卡池仍由 TASK-16 完成。七遗物与七药水已接同源效果，两场原数值战斗测试证明新遗物下一场生效、资源保持和临时状态清除；该测试仅提高起始金币以覆盖购卡交易，不代表平衡通关。完整遭遇/平衡、正式结算和发布验收分别由后续任务验证。

本轮未执行平台编译、存档写入、实机验证或投稿。这些状态须单独记录，不可从本地测试推断。
