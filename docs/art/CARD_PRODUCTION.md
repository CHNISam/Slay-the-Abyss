# 卡牌原生图片/文字 Lua：已验证制作规范

2026-10-23，原神国服7.1。用户操作官方试玩，主 Agent 核对截图。**已通过电脑单卡的显示与点击；这里只放行同结构卡框/卡背/图标的制作，不代表十张手牌、长文案或手机/主机验收通过。**

## 固定流程

1. 以 `data/presentation/ui_theme.json` 和 PR #19 设计为准，数值/名称取项目数据与中文表现层，不改核心规则。上游 Image Editor 固定 `103025f9095d8089e3f9bf097f4d0c5fe039d546`，直接复用其 JSON/Lua/GIA 导出器。
2. 用 [`text-height-compat/card.source.json`](../../art/spikes/card-editor/text-height-compat/card.source.json) 的结构制图；导出 JSON 与 Lua，PNG仅作离线预览。全保留可编辑输入、上游版本、来源/许可和ID映射。
3. 图片与文字模板分别建立，读取返回的真实 templateIndex。`100001/100002/100003` 是图片资产编号，不能用作模板索引。运行时只挂专用容器，原生中文不转成图元。
4. `prepare-card-candidate.ps1 -BaseMap '<干净基底.gil>'` 现在默认选择已实机通过的高度兼容稿，输出 `abyss-art-card-text-v2.gil`。保持 `MILIASTRA_ALLOW_LIVE_WRITE=0`，只写副本。将候选作为新测试存档导入，完成试玩与截图核对。

## 本轮通过的规格

| 项目 | 已验证值 |
|---|---|
| 画布 / 卡框 | 180×240 / 148×208；居中锚点与轴心 |
| 卡面成本 | 11 图片控件 + 4 原生文字控件；另有宿主/诊断控件，不包含在15中 |
| 基础图片 | 矩形100001、圆100002、三角100003；颜色0–255、透明度和层序按上游输出 |
| 标题 / 类型 | 透明文字框高度均40，中心(90,33)/(90,121)，字号17/14 |
| 费用 / 说明 | 40高/22号；132×92说明框/15号；最小字号14，自适应 |
| 绘制生命周期 | 专用容器 `OnStart`，`OnDestroy` 清理；模板关闭遮罩/羽化 |
| 点击验证 | 点“点击检查”后，状态文字变为“点击通过”；只是诊断按钮，不接战斗命令 |

原始22/18高的标题/类型在实机不显示，40高稿两者正常。只改透明框容纳区域，背景条带、中心、字体大小与颜色不变。**40是本轮通过的保守值，未测平台最小高度或其内部padding。**
