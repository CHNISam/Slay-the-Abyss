# 岩金封印遗迹：原生 3D 可审阅样板

本样板执行用户已经批准的同构图方向：左侧破柱、中央战斗留白、右后完整门洞、远山与少量金光。它是等待固定镜头实机审查的原生模型装配方案，尚未作为正式游戏美术验收。UI 沿 PR19；没有修改玩法、核心数值或界面。

## 装配入口

- [摆放数据](../../art/spikes/art-pressure/production-3d.scene.json)：`name/install:false/blocks`，每件有 template、name、position、scale、rotation、solid:false。
- [资产选择清单](../../art/spikes/art-pressure/production-3d.assets.json)：真实目录名称、尺寸、缩略图位置与实例数。
- 名称前缀为 `ARTP3D_`。32 件实例、10 种模型；不要与旧 `ARTS_` 七件负载占位叠放。旧样板只提供模型选型来源。
- 主代理按 `(template,scale)` 建立元件，再按 position/rotation 逐项 createPrefab。同一个 template 有多种 scale，不能只按 template 去重。运行时只创建一次；重启前销毁这轮实例或使用干净副本。
- 本分支不生产或导入 GIA。数据也能被本机 `buildBlockScene` 解析校验；这项离线解析不是正式节点图编译或游戏导入。

## 构图与材质

坐标为米，y 向上，镜头在 −z 看向 +z。以 `[0,0,0]` 为构图中心。核心空场为 `x∈[-4,4],z∈[-2,2]`，只有地面，没有竖向装饰。不要为了填满空场给角色背后加等距石柱。

| 层 | 内容与作用 | 实例 |
|---|---|---:|
| 地面 | 4 块深灰地砖连成 28×28 米底面，上覆一件原生圆形封印石台 | 5 |
| 前景/接缝 | 左右低矮破板、破柱底座铺石、门前台阶，割开底面直线接缝 | 4 |
| 低岩收边 | 左右岩脚与左前景低缘；近景不立高墙 | 3 |
| 左侧主体 | 一根主破柱、一根微倾柱、一根倒柱，两段高度不同的残墙 | 5 |
| 右后地标 | 保留完整开口的门洞，两侧不对称矮墙；门前有单独台阶 | 3 |
| 金色点缀 | 三小处原生含金碎石，只在左前、左封印边缘、门右脚 | 3 |
| 远景 | 六块高岩错开 z/旋转/尺度形成高低山脊，三根小破柱作为遗迹剪影 | 9 |
| 合计 | 部件有重叠连接，避免无关联地排成一行 | 32 |

表中台阶归在前景/接缝行，不重复计数。门洞是官方石质门洞，模型开口本身完整；没有实现门机制或封印交互。石材本色为灰/灰褐，金色来自模型已有矿物。没有自定义染色、发光材质、体积光或特效。

新增三个 ID 均先从已安装 MCP 目录查询，再逐张打开对应缩略图：`20002056` 名称实际是「金属地板」，外观为深灰石砖状板面，用作底面，不把名字误报为石板；`20001043` 为冷灰高岩；`20001044` 为灰褐高岩。后两者组成山岩，避免把原有立方切面石 `20002083` 放大冒充自然远山。其余七种沿用 scene-spike，并重新查看全部七张缩略图。未选绿色草顶平台。模型纹理在本轮没有放大超过 1.62 倍。

## 首轮固定镜头与出生

推荐主代理在独立美术检查副本上使用以下起始值，先看真实画面再微调。参数由已安装 MCP 文档确认可表达，数值属于本轮构图假设，尚未实测：

```json
{
  "camera": {
    "distance": 22,
    "fieldOfView": 43,
    "fixedView": {"yaw": 0, "pitch": 22, "ignoreCollision": true}
  },
  "spawn": {"position": [0, 0.25, 0], "rotation": [0, 0, 0]}
}
```

出生高度 0.25 只用于让角色落到底图承重面，不保证停在该高度；角色跟随镜头的实际目标高度也须读回。需要平移整个构图时，对全部 position 加同一 offset，出生/镜头中心同步移动，不能只挪场景。

22 米/43° 在目标深度约看到高 17.33 米、宽 30.82 米；更远的模型自然缩小。门洞高约 6.49 米，左主破柱约 5.93 米，远山可见高低由下沉量和透视共同形成。主代理先判断门洞是否朝向镜头；如果模型正反不合适，只把门洞 yaw 改为 180°，不要改整套坐标。`ignoreCollision:true` 只防止镜头被原生碰撞推近，不保证视觉无遮挡。

全部部件 `solid:false`，没有额外碰撞、导航、触发器或隐形墙。底图原有地面负责承重；此样板不是可行走边界。四块深灰底板从 x=-14…14、z=-11…17 覆盖主要视锥内草地。`20002056` 的目录厚 0.5 米，而已装 MCP 记录实测 standsAt 为 0.25 米，故按 scale1.4、y=-0.33 估计表面约 0.02 米；圆台按目录厚度把顶面也设在约 0.02 米。圆台没有 standsAt 证据，目录顶面不是已验证落脚面。如果草叶穿透或脚被埋，先实测一块地面，分别抬地砖/圆台几厘米；不能据目录厚度判通过。若底图地面不是 y=0，全组统一加上实测基准高度。

## 环境、灯光与默认天空

不要用默认正午草坪截图作为样板审查结果。建议首先尝试一套名为 `GeoSealDusk` 的原生环境：`hour:18,stars:false,milkyWay:false,clouds:true`。这些参数由本机 `scene_add_environment` 支持；18 点在本底图的实际冷暖与亮度尚未证实。它是黄昏起始方案，并未承诺精确的灰蓝天空或金色夕照。

新增环境仅写入配置，**不会自动应用给玩家**；主代理必须使用返回的真实 environmentId，按已装工具的说明通过 `modifyEnvironmentSettings` 对本轮玩家切换。仅改关卡时钟不能证明天空已改变。若黄昏仍太亮，改用 `hour:0` 的无星无银河夜景，再补适度原生点光；不要为了变暗用不明 fog/color 字段。

已有 `scene_add_light` 确认支持 environment、position、radius、intensity、range。可尝试一盏门侧点光 `position:[5.6,3.4,8.2],radius:7,intensity:1.4,range:70`，以及必要时一盏空场补光 `[0,4,0],radius:10,intensity:1,range:70`；必须归属当前实际应用的环境。这些强度未实测，0～2 盏为上限。工具当前没有公开灯色参数，不能把原生点光宣称为金光；少量金色首先依靠矿石本色。若阴影太黑，应先保角色与敌人轮廓，再调环境或补光。自定义雾、曝光、体积光、天空替换和关闭底图草叶的接口本轮均未证实。

在无 UI 的固定镜头截图里确认无大片绿草、天空不会抢过门洞，再检查真实战斗 UI；已有不透明 backdrop 可能把 3D 全盖住，该状态不能记作背景美术通过。主代理负责单独样板预览以及游戏装配层面的取舍。
