# M1 基础战斗演出（TASK-29）

基于 develop `7fee95e`（含荆棘被格挡吸收与最终格挡封顶 999 修复）；只优化表现，沿用 PR #19 的岩金/钢蓝主题和 C 档点选。规则、数值、随机数和回合仍由同步核心结算，未引入异步战斗系统或新依赖。

## 已实现

- 真实攻击牌飞向目标，随后命中闪光、受击位移、实际伤害/格挡飘字、HP 与残影；格挡牌显示蓝盾，能力/状态用对应状态图标、语义色和层数提示。
- 敌方回合横幅 → 当前行动者及其意图高亮 → 每段攻击/格挡/施法 → 下一敌人 → 我方回合横幅。中毒和荆棘显示状态名、来源日志；死亡淡出后才进入胜负横幅及结果页。
- 玩家实际失血才轻微抖屏；完全格挡不抖屏。普通出牌约 0.4 秒恢复输入，0.6 秒飘字与 HP 残影可并行收尾。多段普通伤害每段 0.2 秒、敌人意图间隔 0.45 秒、回合横幅 0.9 秒，全部取现有 `Theme.motion`。
- `abyss_events` 保存与每个事件对应的轻量视图快照；只复制运行字段，规则表/意图等只读定义共享。`abyss_feedback` 只操作原生控件。UI 消费成功命令新增事件一次，完成后清空已消费帧并保留事件表身份，避免整场累计。
- 表现故障不回滚或重放已提交的规则，恢复最终画面与输入；音效故障单独隔离。替换战斗会取消旧队列与残留效果。宿主只在队列结束后切奖励/失败页面。

## 打击感精修（TASK-29.1）

在 PR #52 的事件队列上只改表现：规则、伤害结算、随机数和事件内容不变，事件仍只消费一次。参照初代 Slay the Spire PC 的反馈机制与节奏（接触帧、命中停顿、按伤害分量抖屏、敌人逐个蓄势出手），岩元素视觉语言独立实现，没有使用他人素材或动画。

| 项目 | PR #52 | 精修后 |
|---|---|---|
| 出牌 → 命中 | 匀速直线飞 0.2 s，到达前一帧消失 | 前 30% 上提蓄势、旅行者后撤，之后加速冲向目标；到达帧就是接触帧，卡牌在命中点缩散（0.12 s） |
| 命中停顿 | 无 | 实际失血的攻击命中停顿 0.05 s，重击（实际伤害+被格挡 ≥ 12）或致命一击 0.1 s；停顿时击退、闪色和数字保持峰值，停顿计入步骤时长 |
| 普通攻击 | 菱形闪光、左右抖动 8 px | 横向岩晶斜光，单向击退 12 px 后缓回，敌人身上泛岩金色；不抖屏 |
| 重击 | 与普通相同 | 等比扩散的岩晶爆裂，击退 16 px，数字放大 2 倍，按伤害比例抖屏 |
| 多段 | 每段相同 | 每段攻击者重新前冲，冲击横竖交替成十字，数字左右交替；每段仍为 0.2 s + 停顿 |
| 群体 | 每个目标各 0.2 s，死亡穿插其中 | 逐帧涟漪落到每个目标，新增横扫带从落点展开，只播一次命中音；击杀延后到横扫结束并成组倒下，只播一次死亡音（三敌两杀 1.6 s → 1.0 s） |
| 格挡 | 盾牌常亮 | 获得：盾牌收拢成形，格挡图标弹一下；完全吸收：盾牌震颤、不抖屏；破盾：盾牌外扩淡出后再扣血 |
| 持续伤害/反伤 | 与攻击相同的菱形闪光 | 中毒/荆棘图标脉冲与紫色闪色；没有命中停顿，中毒不击退，荆棘只轻微后退 |
| 状态生效 | 状态图标淡出 | 图标放大压印，减益下沉、增益上浮，角色半强度语义色闪色 |
| 敌人死亡 | 0.35 s 淡出 | 先岩金闪色，再压扁下沉并淡出，岩晶碎片外扩 |
| 敌方行动 | 高亮后直接结算 | 沿用 0.45 s 间隔做蓄势：攻击意图后撤，非攻击意图上浮；接触帧前冲并播放音效，之后回位 |
| 回合横幅 | 静态显示 | 从左滑入、停留、向右滑出，底板先展开 |
