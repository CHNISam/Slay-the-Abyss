# Battle UI 职责重构（TASK-83）

基线为 6fe3a6e2，包含已合入的正式界面、共享卡框、拖牌和输入修复。不改变规则、主题、控件树或视觉方案。

## 职责与连接

- abyss_battle_ui：组合入口、现有适配器装配和顶层按钮接线。
- input_state：输入归属、战斗/回合/对象有效性校验及失效清理。
- targeting / target_bindings：目标命中、可见槽与实际敌人对应、明确选敌与触点释放。
- card_layout / card_gestures / card_bindings：卡牌姿态、拖动/释放/取消状态转换和原生事件接线。
- render_state / render / render_hud / render_actors：渲染前失效检查、固定调用顺序、资源/奖励与单位表现。
- details / detail_bindings：说明面板与长按/翻页事件。
- actions / action_bindings / potion_bindings：命令、反馈生命周期及动作/药水控件接线。

各职责工厂只接收明确列出的调用端口。前向调用通过组合入口的端口解析，模块不持有完整函数注册表。跨输入控件必须共享的少量归属记录集中在 ownership；平台、控件和既有视图适配器集中在 host。data/presentation 每次从实例读取，使 setData 后不会保留过期闭包数据。没有将原构造器整体搬进另一个模块。
