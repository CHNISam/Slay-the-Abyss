## 规则依据与可信边界

查阅的是初代 PC 的 Ascension 0 条目；不采用二代、桌游或高进阶数值。

- [Lagavulin 社区 wiki](https://slay-the-spire.fandom.com/wiki/Lagavulin)：正常遭遇开场睡眠；最多等待三个敌方行动；实际失去生命会唤醒，刚受伤唤醒的当次行动眩晕；自然醒在第四次敌方行动开始攻击。格挡吸收全部伤害不唤醒。醒后两次攻击接吸魂，循环不再回到睡眠。
- [SlaySpireDB 初代 Lagavulin](https://slayspiredb.com/sts1/monsters/lagavulin)：A0 生命109–111、起始格挡8、睡眠金属化8、攻击18、吸魂降低敏捷及力量。该页同时列有高进阶值，本切片只取 A0。

以上都是公开社区二手资料，不能冒充官方源码审查或本轮原版 PC 实测。原版二进制版本号尚未锁定，完整原版一致性 AC 仍待补该证据。两处一致的数值与 wiki 的完整时序构成这次局部实现依据；未来可用原版战斗录像/实测再复核。死亡冒险者事件的开场清醒例外不在目前遭遇数据中，本切片不实现该事件。

原配置112生命属于 A8+ 的范围；改用 `hpRange=109..111` 实际采样，静态 `hp=110` 仅是内容基准。生命随机消耗战斗 RNG，随后才洗牌，相同种子仍复现相同战斗；不声称随机算法或原作种子的映射已经一致。保留原18攻击值，补齐缺失的敏捷-1。其他22种敌人、本轮卡池、地图及经济不作规则调整。

## 已实现行为

`ai.kind=sleep_then_cycle` 在敌人配置中声明睡眠时长、固定格挡和各阶段意图引用。独立 `abyss_enemy_ai` 管理决策；Combat 负责接入伤害、敌方回合开始的毒伤和行动完成时序。运行状态使用 actor 的扁平字段，兼容出牌失败的原子回滚及现有反馈帧。

| 场景 | 可观察结果 |
|---|---|
| 进入正常精英遭遇 | 109–111随机生命、8格挡、沉睡意图 |
| 不造成失血 | 第1、2次敌方行动后仍睡眠并补8格挡；第3次后自然醒且不补格挡；第4次攻击 |
| 正好8伤害被初始格挡吸收 | 保持睡眠；下一次睡眠行动继续补格挡 |
| 伤害穿过格挡造成失血 | 立即显示苏醒中；本次敌方行动不攻击；下一次开始攻击 |
| 毒在敌方回合开始造成失血 | 当次行动眩晕；后续回合进入攻击循环 |
| 已苏醒 | 攻击18、攻击18、敏捷-1与力量-1；重复三步，不再补睡眠格挡 |
| 致死伤害 | 无活敌意图、正常胜负处理；不额外排入苏醒行动 |

`sleep` / `stunned` 是无效果意图，校验器仅允许这两种意图使用空效果列表，并验证 AI 配置所有引用与阶段种类。其他意图仍要求非空效果。`rules.combat.enemyAI=intent_cycle` 继续表示未配置专属 AI 的默认行为，不能再解释为所有敌人的规则。

表现只读取核心意图：沉睡复用批准稿已有 `Theme.icon.intent.sleep`，苏醒中复用未知意图图标；没有新增布局、颜色、字号、图片资源或动效。实机显示仍待验证。
