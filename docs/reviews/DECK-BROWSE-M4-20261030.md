# M4｜卡组类型筛选与显示排序（Medium）

范围：角色选择的初始牌组预览、冒险中随时打开的完整卡组以及三种只读战斗牌堆。
采用《杀戮尖塔》原版的卡牌类型（攻击/技能/能力/状态/诅咒）与**获得顺序/名称/稀有度/费用排序**的行为参考，另提供类型排序；独立使用现有 Lua 与原生 UI 组件实现；不复制、重新分发反编译游戏源码、UI、贴图或音效。

- 阅读模式顶部六类筛选（含“全部”）；默认展示全部。排序依次切换原顺序/名称/稀有度/费用/类型；每次重新打开恢复默认顺序。
- 原版排序的官方来源：https://steamcommunity.com/games/646570/announcements/detail/1616144864288305862 （2019-07-01 V1.1）。不是原版原生“隐藏非本类型”的筛选，后者是本项目独立扩展。
- 角色选择的初始牌组提供同类别筛选；切换角色或元素重置，六项卡牌文字保持原来布局。
- 筛选/排序仅作用于复制的列表，不能修改永久卡组、UID、当前战斗牌堆或 RNG；空类别显示 0/N。
- 选牌/强制选择、阅读卡牌正文/遗物弹层不启用筛选；延迟 Grid 刷新回调按 generation 防过期。
- 保留原有六列滚动、手柄两行分页、卡牌绘制与触摸退回操作；以 PC 与手机同版本实机验证作为最终验收。
- 验收：分类正确，含升级、重复牌和空类别；排序稳定；关闭后重开重置；抽牌顺序不因浏览改变；手柄/手机滚动、点击和返回不阻塞。
- 当前只完成源码和离线测试候选，未完成官方导入、真实手机性能或验收。
