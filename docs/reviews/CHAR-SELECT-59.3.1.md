## 本次改动与取舍

| 现象（#9） | 根因 | 处理 |
|---|---|---|
| 大圆底叠黑色矩形立绘 | 主题层用 `ring` 圆环 460px + `panelSunken` 深色 320×420 立绘框，图本身是方图 | 去掉圆环与深色框：`portraitFrame` 改为无底色定位容器；立绘位改 400×400 与方图/官方 133 方形人物同比；背后柔光 + 脚下扁椭圆地面光晕，人物"站"在地上 |
| 底部小头像被截半、缩在大框、悬空居中 | 头像 32px 贴在 128×72 横向按钮里，官方头像宿主 1/3 缩放 | 底部钮改 112×112 方形头像卡：72px 头像置于 80px 内框（顶部贴齐），名字落在底部名牌带；官方头像宿主按头像实际尺寸缩放 |
| 左侧全部/攻击/技能/能力/状态/诅咒筛选堆积 | 牌库浏览筛选（#376）照搬进选角卡 | 选角页移除筛选控件与状态；起始牌组按 攻击→技能→能力→其它 排好一次列全，超出 6 种时最后一格汇总，不静默丢牌。牌库界面的筛选不受影响 |
| 生命/金币/遗物挤成一行文字 | 单行拼接 | 名字（标题带）→ 生命、金币两枚并列数值块 → 「初始遗物」小标签 + 名称 + 一句效果 → 分隔线 → 牌组；全部左对齐便于扫读 |

保留牌组列表是偏离原作的自设计：比赛面向新玩家，主人要求初始牌组可读。
