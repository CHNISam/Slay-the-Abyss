# 遗物中文显示名

这是纯展示修复，不是遗物效果或领取能力的实现。`abyss_relic_names.get(data,id)` 优先保留已有中文定义；没有定义或定义仍为英文时，使用本项目中文译名。未知身份显示“未知遗物”，内部 ID 继续留在规则状态与诊断数据中，不进入此显示回退。

正式源目录包含战士130个ID；加上猎人、机器人、观者目录后，联合156个ID都有中文显示名。译名不代表156项官方简中名称均已独立验证，也不改变角色开放范围。

单独核对过的社区来源是[一代黑石护符](https://sts.huijiwiki.com/wiki/黑石护符)与[一代神圣树皮](https://sts.huijiwiki.com/wiki/神圣树皮)。其余缺项采用自然中文的项目译名，已有本项目中文名称保持优先。没有使用二代数据或把社区百科称为官方本地化资源。

回归先在真实奖励控件复现 `SacredBark · 尚不可领取`，修后为“神圣树皮 · 尚不可领取”，按钮继续禁用。专项检查覆盖156个目录ID、已有/缺失定义的同名展示、Darkstone两种身份与未知身份回退，并核对数据、整局字段、队列和队列对象身份不变。没有修改遗物池、效果、随机规则、可领取标记或概率。

只接入节点/商店共享名称与战后精英遗物奖励名称。补充受控真实NodeUI回归：先通过公开流程进入并打开Boss宝箱，再在保留原槽位元数据的情况下逐项显示所有已定义Boss遗物；中文名与source ID名称查找一致，实际描述非空且为中文。这是呈现覆盖夹具，不冒充自然获取记录。原始source ID与本地definition ID的效果查找和领取问题仍由对应实现修复承担。源码、本地回归、候选读回和真机验收分开报告，本切片没有导入或实机证据。
