## 证据分层与复现

构建：`npm run build:data`、`npm run build:ui`、`npm run build:theme`、`node scripts/map-ui-layout.mjs`。逐屏：`node scripts/native-ui-parity-preview.mjs`。原生字体、图库、触控和音画不能由 HTML 预览证明。

本轮没有构建 GIL、官方导入或实机 ready 日志。没有占用鼠标键盘；用户尚未提供本次输入时间窗口。`verify:ui <候选.gil>` 尚未运行，也没有勾选整体 UI、PC、实体手机或手柄实机通过。下一次须先协调时间窗口，统一构建包含已集成正式选角的候选，按同一 hash 执行导入、日志、逐屏取证及 `verify:ui`，不复用本轮离线截图当实机。

最终测试结果与组合核对见本文件下方记录；完整任务仍保留在 TASK-4，设备部分承接 TASK-38、TASK-40、TASK-42 及房间任务。
