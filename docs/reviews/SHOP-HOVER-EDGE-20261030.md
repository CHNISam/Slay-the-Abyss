# 商店下排卡牌上边缘闪动

用户实测：仅左下两张无色牌，在上边缘悬停时百分百上下跳动，另一张下排牌也被联动。其他边缘与上排五张牌未见此现象。

原因：任意卡牌获得焦点时，下排两张牌同步下移20个画布单位；命中区是卡牌的子控件，继承位移和逐帧缩放。鼠标静止在原上边缘时，初始放大量不足以抵消下移，触发离开、复位、重新进入，造成持续循环。

修复：保留卡面缩放、下排避让和价格移动；给既有hit子控件施加反向缩放和位移，使命中矩形始终等于未悬停时的固定货架区域。控件路径、购买命令、商品身份与触屏确认逻辑保持既有实现。

回归：使用真实生成的控件树、Run/Map/Nodes和输入监听，逐帧计算hit继承变换并派发进入/离开。旧实现首先失败于两张下排牌上边缘的静止指针；修复后此用例通过。七张牌四个边缘分别检查60帧保持同一目标，移向邻牌与空白区可正常切换、退出，不扣金币。原有鼠标购买、触屏确认、取消、过期报价和不可购买商品说明仍覆盖。
