# 卡组、遗物入口原生无效对象修复

用户实际进入066adaa5候选后，点卡组和遗物均报`update: attempt to call method 'GetChild' on an invalid object`。先前离线测试和226模块读回不能证明原生生命周期正确，旧包已在本地交付记录标为用户实测失败，文件保留。

原生Grid只保留可见项，刷新及滚动可能替换或销毁旧实例。DeckUI缓存了这些实例，校准1项后刷新完整列表时，下一帧仍对旧实例调用`GetChild('face')`；关闭时清卡图也有相同风险。遗物入口先开关Grid再进入文本页，也会留下失效项。旧共享替身一直复用表，不能暴露失效对象访问，造成了这次漏检。

生产修复在访问子控件前读取官方只读`alive`，清掉失效绑定；update和close共用这条边界，保留现有卡框动画。旧点击和Controller.enabled回调对失效项及已清理绑定直接拒绝，不吞异常、不伪造控件、不把已销毁实例当成隐藏项。官方资料见本机知识库`knowledge/official/guide/mhtakr07vej4.md`的ClientUIBaseControl字段，以及`mhfkrr0i7gds.md`的网格复用说明。

工程保护复用原有`game_ui_fixture`及`check:native-ui-contract`：alive只读、GetChild/GetChildren拒绝死实例，Grid分别支持复用与销毁式刷新、滚动回收。新增回归覆盖校准项替换、连续update、刷新回收、关闭重开、直接开遗物及延迟旧点击；将生产存活保护删掉的负对照必须重现GetChild失效错误。原来写只读alive的旧测试改为存活断言，未增加豁免。共享替身内部读取私有引擎状态，避免递归属性拦截使旧场景超时；原30秒预算不变。

已实证：旧源码新生命周期用例RED，修后5项原生/生命周期/移除保护负对照GREEN；完整旧卡组六组20.466秒、牌堆四组通过；相关17项布局/遗物/历史绑定通过；语法、架构220模块1261边、静态73条原告警且无新增诊断、全部受管函数门槛通过。首次旧卡组在增加替身检查后超时的原输出保留，不当作通过；优化替身内部查表后以原预算完整通过。

替换包仍须单独构建、独立读回及用户实机复验；未取得本轮ready或设备通过。其余79件遗物、节点自身漏释放等旧缺口不在本次关闭范围，M3保持未完成。本轮无鼠标键盘或前台操作。
