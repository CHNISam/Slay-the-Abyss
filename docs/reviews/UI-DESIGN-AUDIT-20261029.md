# 2026-10-29 批准稿与平台实现核对

本轮按用户反馈重新核对整个首局流程。依据为 `docs/design/ui-canvas/README.md`、各屏 `.dc.html` 和后续明确修订；未覆盖页面沿用 PR19 原型、`UI_DESIGN.md` 与 `CINEMATIC_DIALOGUE.md`。以下是源码与离线呈现核对，不能代替同一候选的实机截图和 `verify:ui`。

## 已确认偏差及整改范围

| 页面 | 偏差 | 本轮整改 |
| --- | --- | --- |
| 标题 | 战斗速度选择挤入首屏，批准稿没有此入口 | 移除首屏选择，保持默认普通；不自创设置页 |
| 开局 | 缺少已批准的剧情演出与祝福对话 | 恢复角色确认后的演出、跳过和淡出，再进入合法的祝福对话；不伪造持久历史 |
| 共用菜单 | 尚未启程的查看地图看似可点击，操作无反馈 | 让可用状态与实际处理条件一致，明确启程后可用 |
| 地图 | 将删除节点状态图例误解成删除节点类型说明 | 恢复普通战斗、精英、事件、营火、商店、宝箱、Boss 七类图例；不恢复旧状态图例 |
| 战斗药水 | 缺少拖向敌人松手使用 | 补充目标拖放、预演与取消，保留点击及长按说明 |
| 原创卡牌 | 使用摘要或“附条件效果”代替实际规则 | 逐牌显示条件、对象、次数及收益，固定关键词定义须真实可查；字体不得小于14 |
| 敌人意图 | 仅显示最终值或“已计入”，没有真实算式 | 从核心同一路径取得只读计算步骤；保持原数值、次序及取整 |
| 瞄准 | 旧菱形点列和大圆环偏离最新稿 | 使用14个四尖星、柔光、曲线及四角准星；不改变输入判定 |
| 遗物名称 | 缺定义时把源标识直接显示成英文；黑石护符定义本身也仍为英文 | 为正式源池建立纯展示中文名，保留缺定义状态和原抽取身份；不把翻译当效果实现 |
| 神圣树皮 | 源池能抽到，但缺定义导致无法自然领取；取得树皮后的部分药水仍显示基础值 | 补真实领取、跨幕药效及同倍率说明；固定机制不盲目翻倍 |

卡组与遗物的 Grid 生命周期崩溃另见 `GRID-LIFECYCLE-FIX-20261029.md`，不能只靠隐藏报错或捕获异常视为修复。

用户新增首领宝箱截图中的 `SacredBark` 是可达的原始遗物标识泄露，不是卡牌英文。核查原正式源池有79项缺完整定义，其中63项可经宝箱/部分战后奖励走英文回退，另16项商店已有中文占位；神圣树皮是本轮新增的一项完整实现，其余缺件继续属于M3内容缺口。两参赛角色实际卡池及现有药水名称未检出同类可达英文条目。截图中聚变之锤的空描述，在当前源码及旧4ad包中均有对应中文数据，尚不能据此归因为缺文本，需新候选实机核对。

## 其余页面核查

源码已找到以下批准稿职责的实现：战斗生命、金币、消耗、费用与敌人槽位；独立奖励领取、金币、药水、卡牌、跳过与返回；商店两排商品、价格、触控确认、售罄、删牌与商人对话；营火治疗反馈、十二格分页、升级前后对比；宝箱动画、奖励和三个 Boss 遗物选择；事件左右分栏、四选项、条件及结果；胜利四项统计、重开和双幕平台结算；卡组六列、永久牌只读与关闭；药水及遗物列表。

这表示已核对相应接线，并不表示这些屏幕的布局、长文、官方图片、手机触控或性能已实机验收。不能因源码存在而把这些检查项勾为通过。新的候选仍需按 `ui-acceptance.json` 逐屏留证，特别检查核心信息、文字裁切、遮挡和可用状态。
