# 单体药水拖拽与目标预演

基线 `2f75e075`。批准稿 `docs/design/ui-canvas/README.md` 最新星点/四角准星约定、`Controls.dc.html`和`Potions.dc.html`要求单体药水拖向敌人松手，并与卡牌共用瞄准呈现。旧生产药水输入只有Down/Up/Click，未监听Drag，药水瞄准也没有进入共享轨迹或血条预演。

本片只改 `abyss_battle_ui`、`abyss_battle_card_view` 和 `abyss_battle_damage_view`。药水使用按钮与可见瓶图标均接拖动，起点为相应槽中心；共享`view.potionAim`在拖动时携带`moving/x/y/origin/touch/input`，CardView通过`controls.potionTarget`取得只读有效目标，并复用同一renderArc/renderReticle。CardView不移动牌、不显示出牌阈值线；星点和准星的具体样式由独立批准稿视觉切片合入，不在此片另造样式。

只高亮触点实际覆盖的存活敌人。HP预演在完整隔离Run图上执行真实`Run.usePotion`，包括固定伤害/格挡、药水效果、现有遗物与结算；不会套卡牌伤害修正。中毒使用当下不扣血，故不伪造立即HP损失。真实Run及其RNG、牌组、事件、库存和别名在拖动预演期间保持不变。

有效目标释放只提交一次；空地、手牌区、屏外、NaN或缺释放坐标取消，不消耗、不转成悬空携带。另一触点不能移动或释放当前药水，丢失token、换回合/战斗/库存、缩放、隐藏均使旧释放失效。药水点击后再点击敌人的备用输入、图标点击看效果和长按说明仍保留。未修改GameUI、地图、card_input的手机语义、药水规则、数值、来源或RNG。

验证：旧实现新套件6项真实RED（均为药水/药瓶缺Drag listener），原点击备用项通过；实现后7项全GREEN，分成三个独立进程且各用原30秒预算（6.55/12.57/12.65秒）。补充完整Run/RNG/别名只读断言后首片仍通过。旧药水手势9、选敌5、帮助3、输入所有权7、过期瞄准5项通过。架构220模块/1262边通过；未新增模块。额外旧`card_preview.lua`在第188行因既有卡文案新增“打击类牌。”失败，此片未改文案或该断言，交父线程卡文案切片处理，不冒充它已通过。

这些是生成原生UI替身及真实规则命令的离线验证，不是官方导入或PC/实体手机实机验收。本轮未用GUI或占键鼠；同候选设备拖动和视觉总门禁仍待用户验收。
