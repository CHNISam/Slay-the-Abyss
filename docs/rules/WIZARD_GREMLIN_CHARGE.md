- 构造函数：A0生命范围21–25；A7+改22–26，与本切片无关。基础伤害25，A2+的30不用于A0。
- 初始蓄能为1，getMove选择UNKNOWN类型的蓄能动作；没有格挡、力量或其他状态收益。
- 蓄能动作计数加1；达到3后下一行动为攻击。所以开场两次蓄能，第三次行动造成25基础伤害。
- 攻击动作先将蓄能重置为0，再排入伤害。A0回到蓄能，之后必须三次蓄能才再次攻击。不能把开场两次蓄能当作永远重复的三行动循环。
- 因此十一行动独立预期伤害为 `0,0,25,0,0,0,25,0,0,0,25`。攻击回合是3、7、11。
- 方法体还含逃跑、死亡反应和A17连续攻击分支；本切片不声称实现这些非当前首幕A0普通遭遇路径。

## 旧实现与最小改动

旧数据固定HP23，反复执行格挡3、格挡3、伤害25，既凭空加盾，又在第6、9行动提前攻击。

仅修改现有 `wizard_gremlin` 条目，名称/遭遇/其他敌人不变。HP23保留为位于范围内的定义值，真实战斗使用已有hpRange采样。两个意图分别是空effects的charge和原25伤害attack。窄 `charge_then_attack` 参数记录初始1、上限3及两个意图引用。

`abyss_enemy_ai` 沿用 initialize / beforeAction / advance：每个敌人实例持有标量aiCharge；攻击在伤害前重置，保证致死反伤也不绕过重置；活着完成蓄能后推进下一意图。不新增通用调度器或AI框架，不把buff、睡眠或格挡冒充等待。

Combat只为匹配该策略及chargeIntent的charge开放空effects，并拒绝其非空效果。schema要求空效果、引用和类型正确、整数初始值小于正整数上限。原sleep/stunned例外保留，普通攻击/卡牌的非空effects要求不放宽。真实战斗UI显示“蓄能”，复用既有unknown图标，详情同样显示蓄能；不是防御或增益图标。
