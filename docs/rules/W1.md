## Evidence boundary

This is an initial W1 slice, **not W1 completion or a playable rules-parity update**. The game still uses its previous map and node flows. The new pure reducer is available to the future entry transaction but is deliberately not wired into unverified encounter/RNG handling. Existing map tests describe the previous implementation and are not evidence of StS1 consistency; replace their obsolete topology expectations during the map migration while retaining transaction/security regressions.

The reducer implements the supplied **basic mathematical roll contract**: one injected float, cumulative Monster→Shop→Treasure→Event comparisons, hit reset and miss increase, with integer-percent counters. It accepts base percentages from its caller; verified base values are Monster 10, Shop 3, Treasure 2. It neither generates nor consumes RNG, allocates encounters, handles special relics, nor persists a complete run. Original single-precision accumulation and exact seeded RNG behavior are not proven by injected decimal vectors. It is not used as a substitute for the original-game oracle.

Primary mechanism analysis: [Forgotten Arbiter, Correlated Randomness](https://forgottenarbiter.github.io/Correlated-Randomness/) (retrieved 2026-10-23), plus the package's nine `VERIFIED_BASIC_ONLY` vectors. The page supports the M/S/T ordering, rates and separate event stream. It does not close special-relic or current-build equivalence.
