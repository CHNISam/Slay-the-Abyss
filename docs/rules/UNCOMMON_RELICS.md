# 缺失罕见遗物的生效规则

规则对照固定为 STS1 `319009d5df0a82d9fb0f23cc22322286c6a87ec0` 的同名遗物类，以及 `CardGroup.initializeDeck`、`NextTurnBlockPower`、`AbstractCard.canUse`。本地只保留独立实现。

`abyss_uncommon_relics` 实现本轮 22 项缺失罕见遗物；父集成负责数据注册和领取界面。需要选择的遗物不会用随机代选来完成领取。

| 遗物 | 实际生效方式 |
| --- | --- |
| 日晷 | 每三次战斗中洗入弃牌堆后排入获得两能量动作；初始洗牌不计数，计数跨战斗保留。 |
| 苦无、手里剑、精致折扇 | 每回合每三张攻击牌分别排入一点敏捷、一点力量、四点固定格挡；下一回合清计数。 |
| 开信刀 | 每回合每三张技能牌，对所有敌人造成五点无来源固定伤害。 |
| 墨水瓶 | 所有实际使用卡牌累计十张后抽一张，计数跨战斗保留。 |
| 船夹板、水银沙漏 | 第二回合获得十四点固定格挡；每回合开始对所有敌人造成三点无来源固定伤害。 |
| 自成型黏土 | 每次实际生命损失排入三层下回合格挡；零损失不触发。 |
| 地精之角 | 非最后一名敌人真正死亡时获得一点能量并抽一张；逃离不触发。 |
| 打击木偶、纸青蛙 | STRIKE 标签牌先加三基础伤害；敌人的易伤倍率改为 1.75。 |
| 蓝蜡烛 | 允许打出诅咒，实际打出后失去一生命并耗尽原 UID。 |
| 干瘪之手 | 打出能力时从有效正费用手牌中抽取一张，本回合费用变零；不选 X 费、免费牌、当前使用牌或已排入自动使用队列的牌。 |
| 永恒羽毛、带骨肉 | 进入营地时每五张永久牌回复三生命；胜利时存活且不高于半血则回复十二生命。禁止回血仍然生效。 |
| 问号牌 | 普通卡牌奖励生成数量加一。 |
| 套娃 | 前两次非首领宝箱额外生成遗物，75% 普通、25% 罕见；使用遗物随机流，耗尽后计数为 -2。 |
| 颂钵 | 卡牌奖励允许改选增加两点生命上限，使用永久生命接口结算。 |
| 三种瓶子 | 以永久卡 UID 选择对应类型牌。战斗副本复制瓶标记，初始整副洗牌后按原顺序把先天和瓶牌置于抽牌堆顶；超过五张时保留原有额外抽牌与十张手牌上限。升级与高费用不影响瓶牌定位。 |

战斗回调返回效果数据，由已有动作队列执行。状态沿用 `relicCounters`，卡牌本回合费用沿用现有字段，失败事务保留对象与随机流。瓶标记只绑定实例；静态牌定义中的真值瓶标记、错误类型、重复 UID、非法 UID 仍拒绝。

同轮补齐的公共战斗接点还包括：化学物质零号在十种 X 费牌各自的结算处加二；既有已加二的实现不重复增加。支付与免费自动打出的能量快照保持原值。工具箱先暂停开局抽牌，选完再继续，领取不重新抽取选项。符文金字塔只阻止普通弃手，不冒充保留或跳过虚无耗尽。

跨模块源时序审查另发现并修复了开局 TOP 遗物延迟到首抽后、跨模块重复逆序、正常精英没有投石索、实验分支轮首遗物晚于抽牌、轮首抽牌后遗物晚于能力等问题。轮首与轮首抽牌后均按实际持有顺序逐件派发；TOP 插入同一队列，BOTTOM 保留顺序。干瘪之手排除已排入自动使用队列的手牌。

| 新增开局遗物 | 固定源执行位置 |
| --- | --- |
| 壶铃、巫毒娃娃、针线包、投石索、发条纪念品 | 开战 TOP；按持有顺序逆序执行，普通首抽前已生效。 |
| 贤者之石 | 开战时同步给怪物力量，后续召唤亦同步添加。 |
| 化石螺旋 | 开战 BOTTOM；沿用已验证的普通首抽后顺序。 |
| 疼痛印记 | 开战 BOTTOM，沿用普通首抽后两张伤口进入抽牌堆。 |

本轮离线证据：`uncommon_relics_effects.lua` 13 项、`uncommon_relics_lifecycle.lua` 11 项、`uncommon_relics_x.lua` 12 项；`opening_hand.lua` 10 项。实际 Run 路径包含领取、开战、打牌、下一回合以及工具箱选择。带骨肉先于燃烧之血检查半血门槛，80 上限、40 血胜利后为 58；41 血胜利后为 47；印记禁止二者回血，重复指令不重复结算。另通过故障机器人引擎 63 项、工具卡 52 项、观者流程 28 项、猎人策略 60 项既有回归。此处不代表本轮候选已写入存档或游戏实机验收通过。

`uncommon_relics_opening.lua` 另有 13 项真实事件帧证据：包含上述开局位置、相反获取次序的 TOP 组合与香炉/沙漏 BOTTOM 组合，船舵第三轮首抽前的格挡，以及怀表和扭曲之钳在残暴额外抽牌前按持有顺序处理。怀表先取得时，钳子升级事件的手牌数为 8；钳子先取得则为 5，随后残暴抽牌后均为 9。
